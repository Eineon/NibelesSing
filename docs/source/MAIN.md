- **临时变量**：许多机制会以［N(编号)］的格式存储可变化的值。若未指定变量的具体值，则由使用者自行决定变量代表的值。不同机制的同编号变量不会相互引用。
- **武器伤害骰**：伤害表述中的［[N]WD］代表将相关武器的伤害骰投掷N次并将出目相加，固定值与额外伤害骰不受影响。
- **主副手**：创建角色时，选择1只手作为主手，其他手为副手。
- **敌对行为**：敌对行为是指迫使他人遭受非自愿危害的行为。例如，将火球术施放到人群中是敌对行为，但是打开门时意外放出了一个可怕的怪物并不是。具体由DM裁定。
- **敌人**：你可以使用自由动作指名1个除自身之外的生物，将其标记为你的敌人。你可以使用自由动作撤销标记。
- **同伴**：你可以使用自由动作指名1个除自身之外的自愿生物，将其标记为你的同伴。你可以使用自由动作撤销标记。
- **失去HP**：直接导致「失去HP」的效果不会被视为伤害。
- **损伤**：损伤代表你已失去的HP。消除损伤等同于恢复HP。
- **斩杀**：意义相当于「将**有威胁**的生物的HP降至0时触发效果」。每场战斗中，同一名生物只能触发1次**斩杀**。是否**有威胁**由DM裁定。 \
  当你对一名生物造成至少1点损伤后，若该生物在1轮内被你的同伴**斩杀**，也将其视为被你**斩杀**。
- **充能**：记作「**充能[N]**」。意义相当于「当充能到达N点时，以及之后每高出1点，都会自动触发1次效果」。分别处理不同来源的充能。
- **聚能**：记作「**聚能[N]**」。意义相当于「消耗N点技力，随后激活效果」。
- **血术**：记作「**血术[强度]**」。意义相当于「消耗并投掷［强度］(最低1) 枚HD，再失去等于出目的HP，随后触发效果」，这不会使你的损伤超过垂危阈值。
- **谐振**：以「谐振」作为持续时间的效果将持续10分钟，并会在你参与的遭遇结束时提前结束。
- **韧性**：替换原本的临时生命。韧性可以互相叠加，但拥有名称的韧性不会与同名韧性叠加。职业特性与魔法物品提供的韧性默认为增强韧性。
- **底力**：替换原本的英雄激励。你最多能够同时拥有6点底力，可以重掷已经重掷过的检定。当你完成长休时，底力变为3点。 \
  此外，你可以在自身的1次行动检定掷骰后，消耗1点底力，使检定获得［1PD］点加值。只要底力充足，你可以对同一次检定重复使用这个效果。

### 规则调整
- 优先使用5E2024的资源。你可以向DM申请使用旧版资源。
- 无法使用TCE的额外职业选项。
- 使用**格**取代**尺**作为长度单位，1格为5尺，也等同1.5米。
- 掷出N1的检定将受到10点减值；掷出N20的检定将获得10点加值。
- 黑暗视觉的范围等同视觉范围。
- 原本的固定DC，超过10的部分提升30%，向上取整。
- 背景与职业在人物第1级提供的技能熟练分别降低2项，不足2项则用工具熟练代替。创建角色时，你可以自选合计4项技能与工具获得熟练。
- 智力值到达13点，以及之后每提升4点，你都可以任选1项技能或工具获得熟练，并掌握1门非秘密语言。
- 移除：先攻检定，死亡豁免，阵营，魔法物品稀有度。

### 运算规则

- **最低值**：数值最低通常为0，不会被降至负值。
- **截尾取整**：计算结果出现小数时，通常会舍去小数的部分。例如：3.7取3，-1.2取-1。
- **运算顺序**：对同一数值进行多次运算时，先进行加减，再进行乘除；先进行整数之间的计算，再进行与分数的计算，最后进行与百分比的计算。
- **分数运算**：数值与分数进行乘除前，先将该数值向下取整至分母的最近倍数。例如：分母为4、数值为10时，先将10取为8，再进行计算，不会产生余数。
- **百分比运算**：数值与百分比进行运算时，先将所有百分比与100%相加，得到**全局系数**，再用全局系数乘以原数值。例如：数值增加20%共2次，全局系数等于［100%+20%+20%］。
- **减半**：对数值的减半不属于百分比运算，并且总是在运算的最后进行。同一数值最多只能被减半1次。

### 掷骰
掷骰记作［[N1]D[N2]］，意义相当于「从［1~N2］中随机抽取1个整数，重复［N1］次」。 \
［N1］代表骰子的枚数，［N2］代表骰子的尺寸。抽取的结果称为**出目**，出目的总和称为**骰值**。

只要所用工具能够保证每个整数在理论上的出现概率近似相等，即可用于掷骰，而不限于实体骰子。 \
在本文档中，**骰子**泛指用于生成随机整数的工具，**掷骰**指进行该随机抽取的行为。

对掷骰公式进行的乘法・除法运算，只会将乘数・除数与骰子的枚数做运算，骰子的出目与骰值不会参与运算。
- **翻面**：将出目改为［尺寸+1-原值］。例如，对1D6掷出的2进行翻面，出目将变为5。
- **重掷**：在看到骰子的出目后，重新投掷骰子，以新结果覆盖旧结果。一枚骰子通常只能重掷1次。 \
  给予重掷的效果若没有标注「可以」重掷，则代表掷骰者**必须**进行重掷。 \
  在重掷多枚骰子中的一部分时，由掷骰者决定重掷哪些骰子。
- **调整值**：调整值简称为**修正**。拥有名称的调整值不会与同名调整值叠加，包括各项属性的调整值。 \
  存在以下几种常见的调整值名称：内在、增强、状态、熟练、阶位。这些名称本身不具有任何机制上的作用。原版的职业特性与魔法物品提供的加值默认为增强加值。

#### 优势与劣势
- 当一次检定具有优势时，检定者需要投掷2次D20，并使用较高的出目。拥有多重优势时，多出的每一重优势都会变成1点支援。
- 当一次检定具有劣势时，检定者需要投掷2次D20，并使用较低的出目。拥有多重劣势时，多出的每一种劣势都会变成1点妨碍。
- 同时拥有优势与劣势时，每一重优势都会与一重劣势互相抵消。

#### 支援与妨碍
- 当一次检定拥有支援时，检定者需要在投掷D20后再投掷［[强度]D4］，将最高的出目作为支援加值应用在判定值上。
- 当一次检定拥有妨碍时，检定者需要在投掷D20后再投掷［[强度]D4］，将最高的出目作为妨碍减值应用在判定值上。
- 同时拥有支援与妨碍时，两者的强度会互相抵消。

#### 熟练加值与阶位加值
- （熟练加值:PB）与（阶位加值:RB）都属于无法与同名调整值叠加的冠名调整值。
- PB是一个固定值，计算方式为［⌈人物等级÷4⌉×2］。RB的数值由给予RB的效果决定。
- 原本使用次数等于PB的特性，移除使用次数限制，但每次使用必须消耗1点技力。
- 当你进行拥有熟练的行动检定时，会获得［人物等级÷2］点RB。
- 如果在一次行动检定中同时拥有技能与工具的熟练，你不会获得优势，改为获得1点支援。若有专精，则改为获得2点。
- **熟练骰**：你的熟练骰尺寸为［PB+2］。效果表述中的「**[N]PD**」代表投掷N枚熟练骰并将出目相加。

#### 专精
拥有专精的项目如果能够获得PB，则会将获得的PB增加2点。13级起，改为增加4点。

#### 检定总调整
D20检定的判定值等于D20的骰值加上适用于本次检定的调整值总和。
- **行动检定**的总调整值为［关键属性调整值+PB］，并获得［人物等级÷2］点RB。
- **豁免检定**的总调整值为［关键属性调整值+PB］，获得的RB由职业的豁免倾向决定。
- **武器攻击检定**的总调整值为［AKM+PB］，并获得［WPR÷2］点RB。
- **法术攻击检定**的总调整值为［SKM+PB］，并获得［SPR÷2］点RB。
- **武术攻击检定**的总调整值为［MKM+PB］，并获得［武艺等级÷2］点RB。

#### 被动检定
进行被动检定时，不会进行掷骰，以10作为骰值。
- **优势与劣势**：如果检定拥有优势，则会在被动检定时获得5点加值；若有劣势，则会承受5点减值。
- **支援与妨碍**：被动检定每有1点支援，便会获得1点支援加值；每有1点妨碍，便会承受1点妨碍减值。这些加值与减值最高为4点。

### 属性
创建角色时，你获得40点购点。各项属性的初始值会从6开始，你可以分配1点购点使1项属性的初始值+1，最高18。 \
每次提升人物等级时，你都可以重新分配1点购点，此时最高可以将初始值提升至20。 \
属性调整值的计算方式为［属性值÷2-5］。
- **属性提升**：获得属性提升的属性基本值+2。若会令基本值超过20，则改为+1。同时获得多次**属性提升**时，不能重复选择相同的属性。

#### 基本值与当前值
属性的基本值代表初始值加上所有永久存在、且没有生效条件的调整值。 \
属性的当前值代表初始值加上所有调整值。对属性的引用默认为其当前值。 \
其他记述为基本值或当前值的参数，也参照与属性值相同的规则进行区分。

#### 变体：掷骰决定属性初始值
如果对一成不变的购点感到厌倦，你可以放弃初始购点，使用更加随机的方式决定各项属性的初始值。
1. 你获得24枚D6，将它们分成6组，每组至少分配3枚骰子。
2. 分别掷出每组的骰子，取其中最高的3个结果之和作为该组的骰值，由此得到一个包含6个骰值的序列。
3. 将上述两步重复进行，共计三次，得到三个骰值序列。
4. 从这三个序列中选择一个，将其中的6个骰值分别分配给你的各项属性，作为初始值。
5. 若你选择的序列骰值总和低于72，你获得等于差值的购点，最高可以将属性初始值提升至18。

### [行动检定]{#行动检定}
当你执行【cell:行动】并做出具有风险 (由DM决定) 的行为时，需要采取行动检定来决定结果如何。没有风险的行为可以自由地实现，无需采取检定。 \
你的行动检定加值为［属性调整值+PB］，再加上［⌈人物等级÷2⌉］点RB。如果没有熟练，则不会加上PB与RB。 \
行动检定的流程分为以下步骤。
1. PL决定愿景与熟练
2. DM决定难度与标签
3. PL投掷检定

#### 愿景与熟练
PL的愿景应该是一个当PC克服面临的障碍后，将会达成的实在事件。 \
愿景或许会是"进入庄园"或者"看看都有谁在那栋宅邸里徘徊"。在这两种情况下，障碍都是"宅邸警卫巡逻"，警卫是个有风险的障碍，对PC来说可能会很麻烦。 \
通常来说PL的愿景会很明显，但DM还是需要在必要的时候询问清楚。

PL通过演绎角色的行为决定使用哪一种**技能**、**工具**或**武器**的熟练。使用武器的行动检定同时视为攻击检定。 \
如果PC想大打出手，那就用**武器**。如果PC想发号施令，那就用**权威**。PL需要描述相应的行为，才能使用对应的熟练进行检定。 \
这里当然有一些灰色地带，技能和工具之间有所重叠，愿景也能通过多种手段来实现。这是被特意设计成这样的，具体使用哪种方式由PL自己决定。

#### 难度与标签
DM需要根据PL的演绎来决定这次检定的DC，以及是否拥有支援或妨碍、优势或劣势。 \
根据具体的情景，DM还可以为这次行为添加一些标签，来决定它会与其他效果产生怎样的互动。

#### 投掷检定
PL根据DM设定的难度投掷1D20加上相关修正，根据检定结果引发后果。有时DM不会将DC公开，让PL难以确定行为的后果。

### 时计
时计是一种用于追踪特定任务进展的游戏控件，其进度以**刻度**表示，简称为**刻**。 \
时计由DM创建并管理，DM有权决定是否向PL公开其存在。 \
时计拥有以下3种属性。

- **初始位置**：刻度的初始位置可以是固定值，也可以通过掷骰决定。将时计重置为初始位置时，以掷骰决定的初始位置也需要重新掷骰。
- **推进方式**：根据时计的推进方式，时计的刻度将会随之改变。
- **终止位置**：在刻度推进至终止位置的瞬间，将会激活时计的效果。不具**循环**标签的时计会在效果结算后移除。

#### 时计标签

:::{admonition} 循环
:class: seealso
拥有**循环**标签的时计在效果结算后不会移除，而是将刻度重置至初始位置。
:::

:::{admonition} 无序
:class: seealso
拥有**无序**标签的时计刻度不会按照顺序推进，推进者可以自由选择下一刻的位置。 \
如果PL拥有推进无序时计的权限，DM必须对PL公开该时计。
:::

:::{admonition} 指针
:class: seealso
记作「**指针[N]**」。**指针**会被放置在时计第N刻的位置。 \
在时计推进至该位置的瞬间，将会触发指针后方所述的效果。指针会在效果结算后移除。 \
记作「**循环指针[N]**」的指针因此被移除后，会在时计被重置的同时，再次将自身放置在第N刻的位置。
:::

### 命刻
每当一个具有明确叙事闭环的场景结束时，DM可以宣布为相关角色推进1次命刻。例如，解决一场谜题、完成一次潜入、击败一波敌人、成功交涉获得关键信息 \
你每推进1次命刻，都可以从以下效果中选择1项。
- **回火**：如同完成短休般恢复1项特性的次数・点数，或是触发1项完成短休时生效的特性。
- **自疗**：恢复人物等级4倍的HP。

### 整备
整备是一种轻度活动。任何能够打断长休的因素均会打断整备。 \
你可以将一次整备拆分为多次完成，但会失去整备进度中未满1小时的部分。 \
在2次长休之间，你最多只能进行8小时的整备。


### 动作

#### 行动值
你的最大（行动值:Action Points, AP）初始为3。最大AP为0的期间，你会陷入失能状态。 \
你的回合开始时，若不处于失能状态，则恢复已消耗的AP。

#### 行动权
你可以执行自由【cell:能力】消耗AP来获取行动权。大多数效果都需要消耗对应类型的行动权才能执行。
- 每轮首次消耗AP时，你获得1个反应动作的行动权。
- 每轮消耗的第1点与第4点AP、以及4点之后的每点AP，都会给予1个标准动作的行动权。
- 每轮消耗的第2点AP，给予1个附赠动作的行动权；第3点AP，给予1个移动动作的行动权。

未消耗的行动权会在你的下个回合开始时失效。 \
你无法在处于昏迷・死亡的期间消耗行动权。 \
若无特别说明，你也无法在使用其他动作的途中消耗行动权。

:::{admonition} 转换行动权
:class: seealso
你可以对行动权进行转换，这是一个自由动作。 \
标准动作的行动权可以转换为移动动作，反应・移动动作的行动权可以转换为附赠动作。 \
行动权无法逆向转换，但可以被多次转换。例如，你可以转换2次标准动作的行动权，用它来执行一个附赠动作。
:::

:::{admonition} 自由动作
:class: seealso
你拥有无限的自由动作行动权，可以在任何行动刻消耗。
:::

:::{admonition} 附赠动作
:class: seealso
附赠动作的行动权可以在任意生物的回合消耗。 \
若无特别说明，你无法在一个行动刻内为名称相同的特性消耗多个附赠动作。
:::

:::{admonition} 移动动作
:class: seealso
最大速度为0的期间，你无法使用全力・移动动作获得移动力或进行移动。
:::

:::{admonition} 标准动作
:class: seealso
标准动作的行动权只能在你自己的回合消耗。
:::

:::{admonition} 全力动作
:class: seealso
每个你的回合1次，可以消耗标准动作与移动动作的行动权各1个，获得1个全力动作的行动权。 \
全力动作的行动权只能在你自己的回合消耗。
:::

:::{admonition} 咏唱动作
:class: seealso
某些复杂效果需要数个回合才能成功执行，这种效果会在所需动作的位置记述「**咏唱[N]**」。N代表执行该效果所需的进度。 \
你可以在自己的回合，以自由动作宣言咏唱动作。随后你会进入咏唱状态，持续至效果成功执行，或是宣言另一个咏唱动作。 \
你需要为咏唱维持专注，并在此期间消耗行动权累积咏唱进度。失去专注将会【word:打断】该效果。 \
每回合1次，你可以通过以下两种方式之一累积进度。只要有1轮没有累积进度，效果就会被【word:打断】。
- **全力动作**：消耗1个全力动作累积2点进度。
- **标准动作**：消耗1个标准动作累积1点进度。

在成功执行之前，该效果会维持在宣言阶段，直到进度到达要求才会进入后续阶段。 \
每次宣言咏唱动作时，你需要重新开始累积进度。
:::

#### 衍生动作
作为效果的一部分执行的动作 (例如，通过全力攻击执行的打击动作) 被称为衍生动作。 \
执行衍生动作不会消耗行动权。

#### 动作选项

:::{admonition} 打击【标准动作】
:name: 打击
执行打击动作时，你可以指名1个角色，使用当前持用的1件武器对目标发动1次攻击。 \
这需要你进行1次攻击检定，以攻击目标的AC作为DC。
- **成功**：攻击**命中**，对目标造成武器的伤害。如果你的攻击特别成功，还有可能形成【word:重击】。
- **失败**：攻击**失手**，通常不会对目标造成伤害。你可能可以对攻击目标造成少量的【word:擦掠伤害】。
:::

:::{admonition} 冲刺【全力动作】
:name: 冲刺
执行冲刺动作时，你获得［最大速度×2］点移动力，并立即以直线移动，移动结束时失去剩余移动力。 \
如果以此移动至少2格，你可以选择本次移动经过的任意1格作为起点，执行1次【word:打击】。
:::

:::{admonition} 行进【移动动作】
:name: 行进
你获得［最大速度］点移动力，持续1回合。
:::

:::{admonition} 快步【附赠动作】
:name: 快步
如果你的最大速度不为0，也没有陷入倒地，可以进行1格即时移动，无法进入阻碍区域。
:::

:::{admonition} 起身【移动动作】
:name: 起身
你起身脱离【sign:倒地】状态，这会引发借机攻击。
:::

:::{admonition} 回避【标准动作】
:name: 回避
执行回避动作时，你将获得以下增益，持续至你的下个回合开始：你可见的角色对你发动的攻击检定具有劣势，并且你进行的反射豁免具有优势。 \
如果陷入【sign:失能】或最大速度降至0，你会提前失去这些增益。
:::

:::{admonition} 访问【标准动作】
:name: 访问
通常，你会在做其他事的同时与一件物品进行交互，例如作为攻击动作的一部分来拔出一把剑。 \
当一个物品需要标准动作才能使用时，作为【sign:操作】效果，你需要为其执行访问动作。
:::

:::{admonition} 同步【自由动作】
:name: 同步
每回合1次，当你宣言一个标准・移动・附赠动作时，可以执行同步动作，将该动作进行**封装**。你同时只能拥有1个被封装的动作。 \
被封装的标准动作会在封装时消耗标准动作的行动权；封装移动・附赠动作也会消耗标准动作的行动权，但不再消耗与自身动作类型对应的行动权。 \
在任意角色的回合开始・结束时，你可以使用反应释放封装的动作。
- **释放动作**：被封装的动作数据会固定在结束宣言阶段的那一刻，直到被释放才进入后续阶段。封装与释放动作，不会改变其原本的动作类型。

封装会一直维持，直到被释放、被新的封装覆盖、或你的下个回合开始 (你可以在此之前先将它释放)。 \
你无法封装作为衍生动作宣言的动作。
:::

:::{admonition} 延迟【自由动作】
:name: 延迟
你可以执行延迟动作，将自己的先攻值暂时降降低1点，持续至本轮结束。
:::

:::{admonition} 战技【可变】
:name: 战技
执行战技动作时，你可以发动1项武术，或是使用需要战技动作的特性或物品。 \
战技动作消耗的行动权由对应的武术、特性、或物品决定。若没有进行说明，则消耗标准动作。
:::

:::{admonition} 魔法【可变】
:name: 魔法
执行魔法动作时，你可以施展1道法术，或是使用需要魔法动作的特性或物品。 \
魔法动作消耗的行动权由对应的法术、特性、或物品决定。若没有进行说明，则消耗标准动作。
:::

:::{admonition} 能力【可变】
:name: 能力
执行能力动作时，你可以使用需要能力动作的特性或物品。 \
能力动作消耗的行动权由对应的特性或物品决定。若没有进行说明，则消耗标准动作。
:::

:::{admonition} 行动【可变】
:name: 行动
执行行动动作时，你可以针对特定目标取得进展，具体见【word:行动检定】。 \
行动动作消耗的行动权由DM根据你具体采取的行为决定。

除此之外，你也可以执行行动动作，实现以下这些明确的机制效果。
- **搀扶**：作为【sign:操作】效果，你可以执行标准【cell:行动】，对触及范围内陷入倒地的自愿生物执行访问动作，使其立即执行1次不会引发借机攻击的【cell:起身】。 \
  你不需要为搀扶进行行动检定。
- **保护**：你可以执行标准【cell:行动】，指名触及范围内任意个对你不具全掩护的自愿生物。直到你的下个回合开始，触及范围内对你不具全掩护的目标被未形成重击的攻击命中时，本次攻击造成的伤害由你代替承受，伤害之外的效果依然由原本的目标承受。你需要为此维持专注。 \
  你不需要为保护进行行动检定。
- **协助他人**：你可以执行标准【cell:行动】，协助他人进行行动检定或是攻击检定。 \
  你需要在执行【cell:行动】时指名检定类型，并描述如何进行协助。 \
  如果DM认为可行，则直到你的下个回合开始为止，你可以在被协助的对象进行检定时，使用反应令其检定获得1点支援。你需要为此维持专注。
- **辨识怪物**：你可以执行附赠【cell:行动】，辨识一个可见生物的信息。辨识一个与成功辨识过的生物种族相同的其他生物时，你的行动检定具有优势。 \
  如果辨识失败，直到完成一次长休，或是获得更多关于该生物的情报为止，你无法再辨识相同生物。
- **辨识法术**：当一个可见生物施法时，你可以执行自由【cell:行动】尝试【word:辨识施法】；对于可见的持续中的魔法效果，你可以通过10分钟的专注尝试【word:辨识魔法】。
:::

#### 动作阶段
使用动作的全过程分为以下4个阶段：宣言 \--> 执行 \--> 裁定 \--> 结算。

1.  **宣言阶段**
    - 尝试使用动作时，首先需要将动作的名称提交给DM，这一行为称作**宣言**。
2.  **执行阶段**
    - 你需要明确动作的目标，支付相应的代价，并依次将这些信息提交给DM。
    - 如果无法支付代价，动作将被【word:打断】。
3.  **裁定阶段**
    - 根据动作的效果，采取必要的检定。无需检定则跳过本阶段。
4.  **结算阶段**
    - 对有效的目标结算动作的效果。
    - 若不存在有效目标，动作将被【word:打断】。

:::{admonition} 打断
:class: seealso
:name: 打断
被打断的效果会跳过所有剩余阶段，不进行结算，也不退还已付出的代价。
:::

:::{admonition} 解除
:class: seealso
:name: 解除
被解除的效果会提前结束。**瞬间效果**无法被解除。
:::

:::{admonition} 反制
:class: seealso
:name: 反制
进行反制时，反制者需要进行1次相关的D20检定，对抗被反制效果的DC。
- **反制法术**：以法术反制其他效果时，你的反制调整值为［PB+SKM］，并获得［SPR÷2］点RB。 \
  你施展的法术遭到反制时，反制检定将会挑战你的法术DC。
- **反制武术**：以武术反制其他效果时，你的反制调整值为［PB+MKM］，并获得［武艺等级÷2］点RB。 \
  你发动的武术遭到反制时，反制检定将会挑战你的武术DC。
- **反制特性**：以其他特性反制其他效果时，你的反制调整值为［PB+CKM］，并获得［人物等级÷2］点RB。 \
  你制造的其他效果遭到反制时，反制检定将会挑战你的职业DC。

你能否反制成功，取决于反制检定的结果与反制阶位的差距。 \
进行反制的法术，以及被反制的法术，将法术环阶作为反制阶位。 \
进行反制的武术，以及被反制的武术，将武术强度作为反制阶位。 \
其他效果将［⌈制造者等级÷2⌉］作为反制阶位。
- **成功**：若［目标反制阶位\<=你的反制阶位+1］，则**反制成功**，否则**反制失败**。 \
  若判定值比DC高10点或更多，你的反制阶位+2。
- **失败**：若［目标反制阶位<你的反制阶位］，则**反制成功**，否则**反制失败**。 \
  若判定值比DC低10点或更多，你的反制将自动失败。
:::

#### 指名
进行指名时，你需要在执行阶段将每个对象的称呼提交给DM，作为效果的目标。 \
你使用的称呼不必是对象的真名，但必须足以让DM确定所指的唯一对象。

#### 时点
时点是效果在游戏时间轴上发生的位置，决定了其触发的先后顺序与合法性。 \
所有效果都必须在某个明确的时点进行宣言。你可以自行决定自己制造的效果在同一时点的生效顺序，但不能改变自己与他人制造的效果之间的先后关系。

#### 深入伤害
造成伤害的效果进入结算阶段时，会进行比其他效果更加细致的伤害结算步骤。
1. **确定受害者**
   - 首先需要确定受到本次伤害的唯一受害者。如果同时对多个角色造成伤害，分别处理每个角色的伤害结算步骤。
   - 在此时触发「造成・受到攻击」事件。
2. **确定伤害值**
   - 根据效果确定受害者受到的伤害值。如果同时对多个角色造成伤害，相同的伤害骰只投掷1次。
   - 根据受害者的伤害相性与DR，对伤害值进行调整。先计算相性，再计算DR。
   - 在此时触发「造成・受到伤害」事件。
3. **确定损伤**：
   - 受害者承受等于剩余伤害值的损伤。
   - 受害者可以消耗韧性，抵消等量的损伤。
   - 如果承受至少1点损伤，将触发「造成・受到损伤」事件。


## 战斗

### 先攻值
战斗开始时，你需要进行1次由DM决定的行动检定，这被称为先攻检定。 \
这次检定没有DC，其判定值被称为**先攻值**，用于决定你在本场战斗中的行动顺序。

#### 行动刻
战斗以20个连续的时机为单位推进，这些时机被称为“行动刻”，依次编号为1至20。编号越大的行动刻，其发生顺序越靠前。 \
每场战斗开始前，所有参战者先进行先攻检定以决定各自的先攻值。随后，找出所有先攻值中的最低者，以此为基准。其他角色的行动刻，由基准刻数（1）加上其先攻值与基准值的差额得出，但行动刻最高不超过20。即便差额超过19，也一律落在20刻行动。

例如，若最低先攻为15，则先攻20者将在6刻行动 (差额5)，先攻29者则在15刻行动 (差额14)。若多名角色计算出相同的行动刻，则由PC一方优先进行回合。同伴之间可以自由决定彼此在同一行动刻内的回合顺序。

一轮战斗，指的是从20刻起，依次经过所有较低刻数，直至最低刻数结束的整个过程。即使某个刻数上没有生物行动，它依然计入轮次的时间流动。以“轮”为单位的持续效果，其计时在下一轮该效果最初生效时的行动刻开始时推进一轮 (即该效果于此时减少1轮剩余持续时间)。

### 手下留情
在任何时候，当你采取的敌对行为令目标死亡时，你可以使其免于一死，改为陷入持续1小时的昏迷，并在昏迷结束后以1点HP苏醒。

### 掩护
弱掩护会为AC、DR与反射豁免提供2点状态加值，强掩护为5点。你无法指名全掩护之后的事物作为目标。

### 专注
你可以同时维持最多5个需要专注的效果。以下情况会【word:解除】正在维持的专注。你也可以执行自由【cell:能力】主动解除专注。 \
为专注而进行的行动检定被称为**专注检定**。
- **伤害损伤**：当你一次性受到的来自伤害的损伤到达［6+人物等级×3］点时，必须使用专注进行1次DC为［15+人物等级］的【word:行动检定】。若检定失败，正在维持的所有专注都将解除。 \
  你每额外维持1个专注，这次行动检定便会承受1重劣势。
- **失能或死亡**：若你陷入失能・死亡，正在维持的所有专注都将解除。

### 移动
你可以消耗移动力进行移动。在移动过程中，你可以进行步行、跳跃、翻滚、攀爬、游泳、或飞行。 \
如果你没有相应的特殊速度，部分移动模式会消耗更多的移动力，而飞行则完全不可能。

#### 阻碍区域
因物理环境恶劣或魔法现象干扰而导致生物难以自由穿行的区域被称为**阻碍区域**。 \
被体型比你小不足2级的生物占据的方格，对你而言视为**阻碍区域**。 \
当你尝试进入属于阻碍区域的方格时，需要额外消耗1点移动力。

#### 步行
你在地面上移动，步行进入1格需要消耗1点移动力。步行只能进入与当前格子拥有共角的格子。 \
一次连续移动中，你每进入2次对角方格，该次进入需要额外消耗1点移动力。 \
你可以在每个动作之间、甚至每次攻击之间进行步行，但不能在使用动作的过程中步行。 \
如果你步行离开一个生物威胁范围内的方格，将会引发该生物的借机攻击。

#### 跳跃
你可以执行附赠【cell:能力】消耗2点移动力进行跳跃。你的跳跃长度为［(力量值-9)÷4］格，高度为长度的一半。 \
如果跳跃轨迹包含对角移动，每2个对角方格额外计1格距离。 \
通过跳跃跨越的距离不需要消耗移动力，也不受地面的阻碍区域影响，但会如常引发借机攻击。 \
如果你在跳跃后坠落，将坠落高度减去你的跳跃高度。

跳跃期间，你可以将跳跃高度加在触及距离上，这种短暂的变化不足以改变你的威胁范围。

#### 翻滚
在你的回合中，你可以在地面上消耗1点移动力进行翻滚，这会使你移动1格。你无法在阻碍区域翻滚，也无法翻滚进入阻碍区域，因被生物占据而形成的阻碍区域除外。 \
若你在敌人的威胁范围内翻滚，则需要使用运动・机敏进行1次行动检定，分别对抗每名敌人的攻击DC，成功则本次移动不会引发对应敌人的借机攻击。 \
若你进行的翻滚没有被借机攻击命中，这次移动可以穿越敌人占据的空间，并且首次进入敌人占据的空间不会占用移动距离。 \
每进行1次翻滚，你在本回合后续进行的所有翻滚都需要额外消耗1格移动力。

#### 攀爬
你在垂直的表面上移动，或者倒挂在天花板上。攀爬的规则与步行类似，但如果你没有攀爬速度，攀爬进入1格需要额外消耗1点移动力。在属于阻碍区域的垂直表面上攀爬时，你的每次移动都需要通过一次成功的行动检定，否则将会坠落。

#### 游泳
你在液体中移动。游泳的规则与步行类似，但如果你没有游泳速度，游泳进入1格需要额外消耗1点移动力。在属于阻碍区域的液体中游泳时，你的每次移动都需要通过一次成功的行动检定，否则将会窒息。

#### 飞行
你在空气中穿梭。飞行的规则与步行类似，并且可以在空中悬停。你无法在没有飞行速度的情况下飞行。 \
飞行期间，如果陷入【sign:失能】、【sign:倒地】、飞行速度为0、或死亡，你将坠落。如果拥有悬浮能力，则只会在死亡时坠落。 \
因倒地而坠落时，你可以使用反应进行1次行动检定。成功则从坠落的挤压强度中减去你的飞行速度。

#### 即时移动
记作「**N格即时移动**」，意义相当于「获得N点 (不超过最大速度) 额外移动力，并立即消耗这些移动力进行移动，移动结束时失去这些移动力」。 \
即时移动时，你可以只消耗其中一部分移动力，或是完全不消耗移动力。即时移动不会引发借机攻击。

#### 强制移动
强制移动通常发生在一名生物改变另一名生物的位置时，移动路径由制造强制移动的生物决定。强制移动与移动速度无关，不会引发借机攻击，也不会消耗移动力。 \
身处固体表面相邻方块的生物可以被强制移动推向固体表面，从而造成挤压。


### 危害
危害是指与环境有关的危险。魔法环境的危害，所造成的伤害可能也是魔法性的，具体由DM决定。

#### 燃烧
燃烧中的角色会在其每个回合开始时受到1D4点灼烧伤害。作为【sign:操作】效果，你可以执行【cell:访问】，在地上打滚来熄灭身上的火焰，并因此陷入倒地状态。 \
燃烧的火焰同样也会在被浇灭、淹灭、扑灭时消失。

#### 坠落
如果你在距离地面至少2格的高度坠落，将会在坠落结束时，基于坠落的距离受到挤压。 \
坠落在液体，或者体型比你小不足2级的其他生物身上时，可以使用反应进行1次行动检定。 \
检定成功时，将因坠落而遭受的挤压伤害减半；如果坠落在生物身上，减半的部分由该生物承受，这可能会致其倒地，随后你会落在距离该生物最近的未被占据的空间内。

#### 挤压
当你从半空坠落，或是被强制移动推向固体表面时，将根据承受的挤压强度受到伤害。
- **挤压伤害**：每1点挤压强度会使你受到1D6点物理伤害。如果因挤压承受至少1点损伤，你还会陷入倒地状态。
- **坠落**：挤压强度等于坠落的高度，最高为20。
- **强制移动**：当你已经与固体表面相邻，却仍被强制移动继续推向该表面时，每2格未能完成的推移距离，将会转化为1点挤压强度。

#### 窒息
一个有准备的人类最多可以憋气［1+CON］(最低1) 轮。在战斗外，人类可以憋气10倍长的时间。 \
当剩余憋气时间归零，或者在遭遇呛水及类似情况时，生物将陷入窒息，直到连续1轮自由呼吸。
- **晕眩**：生物会在窒息期间陷入【sign:晕眩】。
- **疲劳**：每当生物结束回合时，将会承受<**疲劳[1]**>。这些疲劳会在窒息结束的1分钟后自动解除。


### 感官

#### 感官敏锐度
感官的敏锐程度分为三个等级，由低到高依次为：**朦胧**、**模糊**、**精确**。
- **朦胧**：你只能得知某事物的存在与否，无法判断其方位或具体细节。人类最常见的朦胧感官是嗅觉，通常侦测范围为1格。
- **模糊**：你能确定目标所在的方格位置，但无法精确定位目标在方格内的具体体态。人类最常见的模糊感官是听觉，通常侦测范围为3格。
- **精确**：你能清晰地感知目标的外形与动作，目标对你可见。人类最常见的精确感官是视觉，通常侦测范围为24格。

若某种感官的敏锐度被降至朦胧以下，则会失去该感官的侦测能力。

#### 深入感官
视觉与听觉的有效距离能够超出其常规范围，但敏锐度会随距离递增而递减。
- **视觉**：有效侦测距离无限。在25至96格内，视觉降为模糊感官；超过96格则降为朦胧感官。
- **听觉**：有效侦测距离为12格。在4至12格内，听觉降为朦胧感官；超过12格则无法侦测。

#### 侦测精度
你对一个目标的侦测精度，取决于所有当前可用的感官中**最高**的敏锐度。
- **朦胧**：目标对你**不可见**。你对目标进行的攻击・察觉检定具有**劣势**。
- **模糊**：你能**定位**目标，知晓其所在方格，但目标依然对你**不可见**。你对目标进行的攻击・察觉检定受到**1点妨碍**。
- **精确**：目标对你**可见**。若你自身对目标不可见，则你对目标进行的攻击检定具有**优势**。

#### 特殊感官
- **昏暗视觉**：在微光环境中视物如同在明亮环境中，忽略微光造成的遮蔽。
- **黑暗视觉**：在微光或黑暗环境中视物如同在明亮环境中，忽略微光与黑暗环境造成的遮蔽。此类感官无法分辨颜色，只能呈现灰度影像。魔法效果制造的黑暗无法被黑暗视觉看透。
- **高等黑暗视觉**：与黑暗视觉类似，但能分辨颜色，且能够看透魔法效果制造的黑暗。
- **振动盲视**：能侦测与自己处于同一固体表面 (地面、墙壁、天花板等) 或同一液体中的事物。
- **心灵盲视**：能侦测具有心智的事物。若目标具有【无感情】特性，则侦测该目标时的感官敏锐度降低1级。

#### 遮蔽
遮蔽会干扰特定感官，降低其敏锐度。
- **轻度遮蔽**：受影响感官的敏锐度降低1级。
- **重度遮蔽**：受影响感官的敏锐度降低2级。


### 攻击

#### 体术
使用**体术**取代徒手打击。体术是一种具有「轻型」词条的**肉体武器**，造成0档物理伤害。 \
如果不具体术熟练，将无法使用体术制造威胁范围，其攻击检定也不会获得PB。

#### 借机攻击
只要生物移动离开你的威胁范围内的方格，就会引发你的借机攻击。 \
你可以执行自由【cell:战技】发动借机攻击，在你的2个回合之间最多只能发动1次。 \
当你无法发动借机攻击时，也无法使用需要消耗借机攻击的效果。

当你威胁范围内可见的生物使用【sign:操作】效果时，该生物会引发你的借机攻击。 \
以下行为拥有【sign:操作】标签。
- 拔出・捡起武器
- 打开一扇门・窗户
- 将一件物品放入・取出一个容器
- 其他由DM决定的行为

即将因使用【sign:操作】效果而引发借机攻击的生物，可以进行1次专注检定，对抗你的攻击DC，成功则不会引发借机攻击。 \
若该生物同时被多个生物威胁，它只需要进行1次专注检定，分别对抗每名威胁者的攻击DC。

借机攻击重击时，引发借机攻击的行为会被【word:打断】。
- **打断移动**：目标立即停止移动，并失去剩余的移动力。
- **打断施法**：目标施法所用的行动权被浪费，但不会产生其他消耗。

#### 武器交互
你可以执行附赠【cell:能力】拔出武器，也可以作为一次至少2格的直线移动的一部分。 \
每回合1次，你可以执行自由【cell:能力】将武器从一只手换到另一只手，或是交换两只手上的武器。

尝试拔出武器时，你的每只空手都可以拔出1件武器。你可以在自己的回合，执行自由【cell:能力】将被拔出的武器重新收起。 \
拔出肉体或白刃武器尽管拥有【sign:操作】标签，但不会引发借机攻击。

> **》拔出与收起肉体武器** \
> 拔出与收起肉体武器属于自由动作，并且可以在你的回合外执行。 \
> 拔出肉体武器并不意味着你需要血淋淋地摘下自己的器官。它仅仅代表你亮出尖牙、弹出利爪、或者攥紧久经锻炼的拳头，锋芒毕露，蓄势待发。 \
> 同样，你也可以随时收敛杀意，缩回爪子、闭上嘴巴、或者把拳头揣进口袋。这一切的视觉表现取决于你的创意。 \
> 与人造武器不同，无论是否收起肉体武器，都不会影响你能否持用肉体武器。这意味着你可以在收起肉体武器的状态下用它们制造威胁范围。

#### [突袭]{#突袭}
你会在遭到突袭时承受以下效果，持续至你的第一个回合结束。
- **措手不及**：你陷入迟钝状态，并且无法在自己的回合外使用动作。
- **破绽**：你陷入【sign:破绽】。

#### [重击]{#重击}
如果攻击检定的判定值比DC高10点或更多，这次攻击将形成**重击**，额外造成［[攻击PB]D10］点重击伤害，伤害类型与攻击相同。 \
重击不会翻倍伤害骰，并移除所有扩大重击范围的效果。
- **N1与N20**：攻击检定掷出N1/N20不会再自动失手/自动命中并重击。

:::{admonition} 免疫重击
:class: seealso
免疫重击的生物不会受到重击伤害。 \
免疫重击的爪牙受到重击时依然会立即死亡。
:::

#### 威胁范围
持用具有熟练的近战武器期间，你能够制造相当于触及范围的威胁范围。 \
你无法威胁对你具有全掩护的空间。处于失能状态时，你无法制造威胁范围。

#### 反击
当你被可见生物指名为攻击目标时，若该攻击对抗你的AC，则可以在攻击者投掷攻击检定后、DM宣布结果前，使用当前持用的1把武器对其进行1次承受2点减值的攻击检定作为反击。
- 反击不是攻击，不会选择攻击目标，也不会对抗攻击者的AC，而是将攻击判定值作为对方攻击检定的DC。
- 你不能在无法发动借机攻击时进行反击，并且针对每次攻击只能进行1次反击。
- 即便攻击者不在武器射程内，你也可以进行反击。如果攻击者的攻击失手，则代表反击成功；反之则为反击失败。

反击成功时，若攻击者身处近战反击的触及范围、或远程反击的首个射程增量内，你可以令反击对攻击者造成武器的基本伤害，加入的属性调整值最高为0。 \
如果使用你的攻击判定值对抗攻击者的攻击判定值，能够满足重击的条件，反击也能造成重击伤害。

#### 伤害档位
武器的伤害档位用于决定其伤害骰的基础尺寸与枚数。伤害档位为0档或更低的武器只能造成1点伤害，不会进行伤害检定。
| 档位  |   伤害骰   |
| :---: | :--------: |
|   1   |    1D4     |
|   2   |    1D6     |
|   3   |    1D8     |
|   4   |    1D10    |
|   5   |    2D6     |
|   6   |    2D8     |
|   7   |    3D6     |
|  8~9  |    4D6     |
|  10+  | [档位÷2]D6 |

#### [擦掠伤害]{#擦掠伤害}
当你使用具有熟练的武器发动的攻击失手时，若判定值比DC低不超过5点，依然可以对目标造成［伤害档位］点擦掠伤害，伤害类型与武器相同。 \
你在反击时无法造成擦掠伤害。若你的攻击被成功反击，你也无法造成擦掠伤害。

怪物发动的武器攻击不会按伤害档位造成擦掠伤害，而是固定造成［生物等级］点擦掠伤害。

#### 攻击DC
攻击产生的效果有时会要求目标进行1次对抗攻击DC的豁免检定。 \
攻击DC等于一次被动攻击检定的判定值。

#### 瞄准空间
当你发动不需要指名可见目标的攻击时，可以不瞄准特定的角色，而是以空间中的任意一点作为目标。此时攻击检定的DC为5。 \
你可以通过这种方式投掷喷溅武器。由于这种武器通常能够对以落点为中心的一片区域产生影响，在特殊情况可能会产生比瞄准特定角色更好的结果。攻击检定失败则意味着武器丢到预料之外的地点，通常不会产生效果，但也可能导致戏剧性的后果，具体由DM决定。 \
对于其他武器，这种攻击方式永远不会意外命中其他角色。

#### 典型豁免
如果一个效果允许你进行拥有「典型」前缀的豁免检定，代表你可以通过豁免检定改变自身遭受的效果。 \
如果你选择不进行豁免检定，则会受到如同豁免失败的效果，但不会形成特殊失败。
- **成功**：你受到一半伤害。若豁免判定值比DC高10点或更多，还会形成特殊成功，使你免受伤害。
- **失败**：你受到全额伤害。若豁免判定值比DC低10点或更多，还会形成特殊失败，使你额外受到［[效果制造者PB]D10］点相同类型的伤害。

#### 双持攻击
执行【cell:打击】时，作为**绝技**效果，你可以执行附赠【cell:能力】进行双持攻击，令这次【cell:打击】能够以副手武器额外发动1次攻击。
- 进行双持攻击时，主手发动的攻击检定将承受4点减值，副手发动的攻击检定将承受6点减值。
- 如果副手为肉体・轻型武器，则主手与副手攻击因此承受的减值降低2点。
- 进行双持攻击时，你无法将属性调整值加入副手攻击的伤害中，除非该调整值为负值。

#### 夹击
你与至少1名同伴满足以下所有条件的期间，你们会对目标敌人形成夹击，此时目标对抗你们发动的攻击具有**破绽**。
1. 你与同伴分别身处目标所在方格的对侧或对角。如果目标占据多个方格，任意方格满足条件即可满足此条件。
2. 目标同时处于你与同伴的威胁范围内。
3. 目标对你与同伴可见。
4. 你能够与同伴交流。


### 战策
若无特别说明，你只能选择触及范围内，对你可见且不具全掩护的生物作为战策的目标。
- **战策攻击**：一部分战策需要你发动攻击。你可以将通过【cell:打击】或借机攻击发动的任意次武器攻击替换为战策攻击。 \
  若无特别说明，战策攻击不会造成任何直接伤害，例如基础伤害、额外伤害、擦掠伤害、横扫伤害。

#### 推撞
你需要有空手才能发动推撞，以你的体术触及范围作为推撞范围。 \
使用体术对目标发动1次近战攻击，对抗目标的**被动反射**。如果目标体型大于你，其**被动反射**获得优势。
- **成功**：将目标往任意方向直线强制移动最多［1+(判定值-DC)÷5］格。强制移动目标时，你可以跟着目标一起移动，这不会引发目标的借机攻击。
- **失败**：若判定值比DC低6点或更多，你将失去平衡，陷入倒地状态。

#### 擒拿
你需要有空手才能发动擒拿，以你的体术触及范围作为擒拿范围，目标体型不能比你大超过1级。 \
使用体术对目标发动1次近战攻击，对抗目标的**被动反射**。以你的体术攻击DC作为擒拿的挣脱DC。
- **成功**：目标陷入受擒状态，此时你可以将其强制移动至距离你最近的未被占据的空间。
- **失败**：若判定值比DC低6点或更多，你将陷入破绽状态，持续至你的下个回合开始。
- **紧勒**：你可以执行移动【cell:战技】，以体术对受擒于你的任意个生物造成［1WD］点伤害，目标可以进行1次对抗你的体术攻击DC的典型强韧豁免。 \
  紧勒不属于攻击，也不会进行攻击检定，因此不造成那些要求你攻击命中的附加效果。
- **一手一擒**：每只手在同一时间最多只能擒拿1个目标。 
- **结束擒拿**：受擒目标可以执行【cell:访问】，进行1次行动检定来对抗挣脱DC，成功则结束受擒状态。 \
  若你陷入失能，或是目标离开擒拿范围，受擒状态也会提前结束。你可以执行自由【cell:能力】释放目标。

#### 缴械
你尝试击落1个目标身上携带且对你可见的1件物品，目标体型不能比你大超过1级。 \
使用徒手或武器对目标发动1次近战攻击，对抗目标的**被动反射**。如果目标以至少2只手持握该物品，其**被动反射**获得优势。
- **成功**：该物品将掉落在原地。如果你有空手，则可以尝试接住该物品。
- **失败**：若判定值比DC低6点或更多，你用于发动缴械的武器将掉落在原地。

#### 虚招
你尝试用误导性动作让能侦测到你的1个敌人对你真正的攻击毫无防备。你可以执行移动【cell:战技】发动虚招。 \
进行1次行动检定，对抗目标的被动察觉。如果以【无心智】生物作为目标，其被动察觉获得优势。
- **成功**：目标对抗你的下一次近战攻击具有破绽，持续1轮。若判定值比DC高5点或更多，目标会在相同时间内对抗你的所有近战攻击具有破绽。
- **失败**：若判定值比DC低6点或更多，你对抗目标的所有近战攻击具有破绽，持续1轮。

#### 兵胁

### 伤害

#### 生命值
你在1级时的最大HP为［体质值+职业生命骰尺寸+CON］点，升级时取满你的职业生命骰。

#### 浴血
你的浴血阈值等于［最大HP÷2］。你会在损伤超过浴血阈值期间处于浴血。

#### 伤害类型
将原本的伤害类型整合为以下伤害类型。
| 类型  |               范例               |
| :---: | :------------------------------: |
| 物理  |         钝击、挥砍、穿刺         |
| 腐蚀  |            强酸、暗蚀            |
| 灼烧  |         火焰、闪电、光耀         |
| 冷冻  |               寒冷               |
| 虚弱  | 毒素、流血、磨损、枯竭、精神压力 |
| 力场  |  音波、重力、空间撕裂、奥术能量  |
| 纯化  |  生命或死亡能量、神圣或亵渎能量  |

#### 伤害相性
生物对不同类型的伤害具有相性，共分为五类：毁灭、易伤、通常、抗性、免疫。
- **毁灭**：受到拥有毁灭的伤害时，必须进行1次对抗造成伤害的效果DC的强韧豁免。 \
  失败则本次伤害值获得［最大HP］点加值；成功则只获得［自身等级×2］点加值。
- **易伤**：你每次承受的拥有易伤的伤害+50%。
- **抗性**：你每次承受的拥有抗性的伤害减半。若减半后的伤害值不超过［PB］点，你不会受到伤害。

#### 伤害减免
拥有（伤害减免:Damage Reduction, DR）的角色能够降低自身所受的攻击伤害。 \
攻击对拥有DR的角色造成的攻击伤害、擦掠伤害与横扫伤害会降低等于DR强度的数值，反击造成的伤害也会被降低。力场与纯化伤害不会受DR影响。 \
如果武器攻击的武器伤害被DR免除，这次攻击不会使攻击目标承受任何响应「造成・受到攻击」或「造成・受到伤害」的非自愿效果。


### 垂危
你的垂危阈值等于［最大HP-人物等级×4］。你会在损伤超过垂危阈值期间处于**垂危**，面临遭受**处决**的风险。

#### 处决
作为全力动作，你可以对1格内可见的1名垂危生物进行处决。
- 在敌人的威胁范围内进行处决会引发其借机攻击。
- 进行处决时，你需要发动1次武器攻击，此次攻击会自动命中并重击。
- 目标因处决承受至少1点损伤时，若HP未降至0，则必须进行1次对抗你的攻击DC的体质检定，失败则HP降至0。

#### 濒死
当你的HP降为0且没有立即死亡时，将会承受1级**濒死**状态，持续至你完成长休或是死亡。如果你的基本体质21+，濒死的持续时间缩短至1小时。 \
你的死线基础为3。濒死级别超过死线时，你会死亡。

濒死级别每次增加后，直到伤势稳定或濒死解除为止，你的损伤无法被治疗。直到恢复至少1点HP为止，你还会陷入昏迷。


## 起源
背景与种族不再提供属性值提升。

### 谱系
取代原本的生物类型，所有生物都属于以下谱系之一。
- **凡**：具备基础认知能力与自我意识的非魔法生命体。涵盖人类在内的大部分动物。
- **械**：通过人工技术构建的生命体，通常缺乏情感与欲望，依赖预设逻辑运行。
- **妖**：源于神秘本质的原生超自然存在，例如妖精、龙类以及其他魔法生物。
- **异**：源于神秘本质的异界超自然存在，例如天使、恶魔以及其他跨位面生物。

#### 原型
除了谱系之外，生物还会拥有多种原型。以下列出了一系列不具任何效果的特征原型，主要用于决定生物与其他效果的交互方式。
- **异怪**：异怪通常具有奇异的生理结构，千奇百怪的特殊能力，怪异的思维方式，或者这三者的任意组合。
- **动物**：动物代表非人的活体生物，通常为不具有魔法属性也不具有语言和文化天赋的脊椎动物。
- **构装体**：构装体是活化的物体，或人工建造的生物。
- **龙类**：龙类是有着古老起源的有鳞生物，他们通常有翅膀、具有魔法和非凡的威压。
- **精类**：精类是与妖精荒野或自然力量有关的生物，他们通常具有人类的外形。
- **人类**：人类通常只有少量超自然能力，或者完全没有。他们大多数可以用语言交谈，普遍拥有较为发达的社会结构。
- **魔兽**：魔兽是有着怪异起源的非自然生物，他们通常具有超自然能力，但有时候仅仅是在外表或习性上奇特而已。
- **泥怪**：泥怪是无具体形状或易变形的生物，通常没有心智。
- **界外体**：界外体至少有一部分本质是主物质位面以外的某个位面的产物。一些生物可能原本属于其他原型，当他们达到更高 (或更低) 层次的精神状态时变成了界外体。
- **植生体**：植生体是有意识的植物或真菌生物，他们和普通的植物与真菌不一样。
- **亡灵**：亡灵曾经是活物，但在死去以后被神术或异能力量活化，成为了不死者。

- 如果种族的移动速度超过6格，则将超出的部分视为内在加值。

- 移除：侏儒，半身人，兽人，龙裔，阿斯莫，提夫林。

### 缺陷
缺陷经历是角色的内在枷锁，源于创伤、执念或致命弱点。 \
创建角色时，你可以获得最多3项缺陷。DM随时可以要求你修改缺陷。

当你或DM认为你的某项缺陷符合当前情况，将会触发你的缺陷，为你提供1点底力。 \
触发缺陷会为你带来麻烦。如果你需要为之进行检定，本次检定将自动失败；否则，将产生一些由DM决定的不利影响。例如，因"赌徒心态"在谈判中孤注一掷，反而彻底激怒了对方。

#### 改变缺陷
如果你在游戏过程中发现之前获得的缺陷不再合适，你可以在间章向DM描述角色的转变，随后修改、删除或添加你希望的缺陷。

### [武器熟练度]{#WPR}

如果进行兼职，分别计算每个职业的WPR并加在一起，最后将小数向上取整。 \
无论如何，你的WPR永远无法超过人物等级。

### 豁免

- **强韧豁免**：取代体质豁免与魅力豁免，关联属性为CON与CHA。

根据你的（法术熟练度:Spell Proficiency Rank, SPR），拥有熟练的法术攻击检定会获得［SPR÷2］点RB。 \

高阶SPR职业的SPR等于［职业等级］级，中阶SPR职业的SPR等于［⌈职业等级×$\frac{3}{4}$⌉］级，低阶SPR职业的SPR等于［⌈职业等级÷2⌉］级。 \
如果进行兼职，分别计算每个职业的SPR并加在一起，最后将小数向上取整。 \
无论如何，你的SPR永远无法超过人物等级。

### 技力
你拥有［2+(人物等级+基本职业属性值-9)÷4］点技力。部分职业特性需要通过消耗技力发动。 \

#### 拳斗士

##### 1级：拳斗

##### 1级：钢颚铁护

*调整同名特性* \
你战胜逆境的经历让你在战斗时充满勇气，这种自信表现为你的锐气。你的拳斗士等级决定了你拥有多少点锐气，具体数据见拳斗士特性表中的锐气一列。 \
你可以消耗锐气来增强或启动特定的拳斗士特性。你一开始掌握三种特性：振奋精神，左右开弓，寓攻于走。细节见下。 \

### 变体
你随时可以为拥有等级的职业选择满足条件的变体。 \
若所选变体的先决条件失效，你将暂时失去该变体提供的所有能力，直到重新满足条件。

#### 特性变体
你会在达到指定职业等级时，获得所选的特性变体。特性变体通常会替换・调整原有的职业特性。 \
你选择的特性变体必须能成功应用于你的职业。如果该特性变体尝试替换・调整你并不拥有的特性，或者与你已选的其他特性变体发生冲突，你无法选择该特性变体。 \
暂时失去特性变体时，其对原有职业特性的替换・调整不会还原。

#### 职业变体
职业变体是数个特性变体的固定组合。当你选择一个职业变体时，必须接受其包含的全部特性变体，无法拆分选取。 \
只要该职业变体包含任何无法成功实现替换・调整、或与你已有特性冲突的特性变体，你便无法选择该职业变体。


### [魔宠]{#魔宠}
当获得给予你魔宠的特性时，会获得【宠物傍身】作为奖励专长。你的宠物拥有不同于一般动物的特殊能力。

#### 基础能力

##### 心灵连接
你的魔宠距离你20格内期间，你可以与其进行心灵交流。你还能执行附赠【cell:魔法】将自己的视听觉切换到魔宠的感官，持续至你下一回合开始。在此期间，你同时享有该魔宠自身的特殊感官。 \
当你施展施法距离为触碰的法术时，你的魔宠可以帮你传递这道法术。此时你的魔宠必须距你20格内，且在你施展这道法术时你的魔宠需要执行一个反应才能将其传递。

##### 解散魔宠
你可以执行【cell:魔法】暂时解散你的魔宠，将其送入一个口袋位面。 \
随后，你可以执行【cell:魔法】使其重新出现于6格内你可见且未被占据的空间中。 \
当魔宠的HP降至0时，它会被永久解散。你也可以执行【cell:魔法】主动将其永久解散。 \
当魔宠通过任意方式解散时，它会将自己穿着或携带的任何物品留在自己曾占据的空间中。 \
作为一个消耗10分钟与1把金币的仪式，你可以获得一只新的魔宠，之前的魔宠将被永久解散。在2次长休之间，这个仪式最多只能举行1次。

##### 专属能力
为你的魔宠从宠物能力、魔宠能力和主人能力中选取合计2项能力。你可以在完成长休时重新选取能力。 \
你不能替换掉魔宠的天生能力。例如，你不能不给猫头鹰魔宠选择飞行能力。

#### [宠物能力]{#宠物能力}
- **两栖**：宠物同时拥有步行与游泳速度，都等于它的最高步行或游泳速度。宠物可以在空气和水中呼吸。
- **掘地**：宠物获得1格掘穴速度。宠物可以在身后留下微型地道。
- **蛛行**：宠物获得6格攀爬速度。
- **飞掠**：宠物获得6格飞行速度。宠物飞行离开敌人的威胁范围时不会引发借机攻击。
- **黑暗视觉**：宠物获得黑暗视觉。
- **敏锐嗅觉**：宠物获得2格基于嗅觉的盲视，并且基于嗅觉的行动检定获得1点支援。

#### 主人能力
- **吸纳魔宠**：你的魔宠可以变成你肉体上的一处印记，通常看上去像是一处胎记，纹身，或宝石，略微像是魔宠的通常模样。当处于变身状态，魔宠不能行动，除非变回魔宠。它不会被区域效果影响，必须被单独指定为目标时才能影响到它，这需要知晓它是一个生物。生物需要使用察觉执行【cell:行动】并成功通过1次对抗你法术DC的行动检定，才能意识到它其实是一只魔宠。你的魔宠仍然可以通过心灵连接来交流其感受。从魔宠和变身形态之间变化需要你维持1分钟的专注。

## 装备

### 金币
**金币**代表你在冒险中积累的财富，可用于购买物品、消耗品与装备。 \
金币以三种单位计量：**把**、**袋**、**箱**。每把金币的价值约为10GP，换算关系如下所示。你不必在意单价不足10GP的非魔法物品储备。
- 10 把 = 1 袋
- 10 袋 = 1 箱

当某一单位的标记槽填满时，需要向上进位并清零当前单位。
- 例如：持有 9 把时再获 1 把 → 转为 1 袋，把数归零。
- 持有 9 袋时再获 1 袋 → 转为 1 箱，袋数归零。

若金币总量超过1箱，需要先将超额部分存入安全地点，才能继续获得金币。 \
金币的价值是抽象的，无需精确计算每一枚。若你想打赏侍者、向许愿井投币，或进行其他小额支出，只需示意即可，不必拘泥具体数额。

### 携带装备
你可以通过以下3种方式携带装备。
- **抓握**：用手握住的装备。一只手能抓握的装备数量由你自己决定。 \
  被效果要求**持用**的装备，需要你按照合理的方式 (由DM决定) 抓握。 \
  你可以使用自由动作扔掉抓握的装备，或是改变抓握方式，这不会引发借机攻击。
- **穿戴**：未用手拿住，但随身携带的装备。例如鞘中的剑、口袋里的药水、穿好的盔甲。 \
  你可以自由决定穿戴装备的方式。例如在布甲外面套一层板甲，在每根手指上戴一枚戒指。至于穿戴方式能否发挥装备的作用，DM拥有最终决定权。 \
  作为【sign:操作】效果，你可以使用附赠动作在抓握与穿戴之间切换1件装备。 \
  根据DM的判断，部分复杂的装备可能需要更长时间才能完成穿戴。
- **收纳**：放置在当前穿戴的容器内的装备。 \
  作为【sign:操作】效果，你可以执行【cell:访问】从容器中取出・放入1件装备。

#### 持用武器
你的每只手同时只能持用1件装备。
- **共持**：用至少2只手持用，且其中包含主手的握法被称为共持。被共持的武器攻击视为主手攻击。
- **副手攻击**：以副手使用武器发动的攻击，加入伤害检定的属性调整值若为正值，则会减少2点 (最低0)。
- **肉体武器**：拥有肉体武器的肢体没有持用任何物品的期间，该肉体武器视为被主手持用。肉体武器通常无法共持。
- **全力攻击**：进行全力攻击时，你必须选择1个武器，使用该武器之外的武器发动的攻击都视为副手攻击，包括肉体武器。

#### 殖装
殖装是被植入宿主体内的装备。如果你拥有工艺技能的熟练，可以通过1小时的整备为1个自愿・昏迷的生物植入・移除1件殖装。你通常无法自己为自己植入・移除殖装。 \
一旦移植完成，被植入的对象就可以开始使用殖装。殖装会成为对象身体的一部分，无法单独受到伤害。


### 武器

#### 武器类型
常见的武器分为以下4种类型。肉体武器之外的3种武器又被统称为**人造武器**。
- **肉体武器**：作为角色身体一部分而存在的武器。这种武器无法直接购买。拥有天生武器的角色对自身所有肉体武器具有熟练。
- **白刃武器**：所有需要依靠角色自身力量进行近战格斗的冷兵器。部分白刃武器十分适合投掷，可以用于发动远程攻击。
- **射击武器**：利用机械结构、火药爆炸或能量释放来发射弹药的远程武器。使用射击武器通常需要消耗弹药，装填・取出弹药会引发借机攻击。
- **喷溅武器**：能够对一定区域造成范围破坏的特殊武器。喷溅武器通常是消耗品。从容器中取出喷溅武器会引发借机攻击。

#### 武器模板
取消原本的所有非魔法人造武器，你现在通过购买武器模板设计自己的武器。

|   模板   | 伤害  | 价格  |
| :------: | :---: | :---: |
| 简易武器 |  2档  |   F   |
| 军用武器 |  3档  |  2把  |

购买模板时，你需要决定它属于**白刃武器**还是**射击武器**。若为射击武器则获得「弹药_10」与「助进」词条。 \
你可以为武器模板添加任意项改装。通常不能重复添加相同的改装，也无法添加会将伤害降至0档的改装。
- **投掷**：仅限白刃武器。武器的伤害档位-1，获得「投掷_4」词条。支付1把金币，令对轻型武器添加的此改装无需降低伤害档位。
- **触及**：仅限白刃武器。武器的伤害档位-2，获得「触及」词条。
- **残暴**：仅限白刃武器。支付1袋金币，可以使用该武器代替体术发动【推撞】战策，并且为此进行的攻击检定获得专精。
- **绞缠**：仅限白刃武器。支付1袋金币，可以使用该武器代替体术发动【擒拿】战策，并且为此进行的攻击检定获得专精。
- **华丽**：仅限白刃武器。支付1袋金币，使用武器发动【缴械】或【虚招】战策时，你为此进行的检定获得专精。
- **灵巧**：仅限白刃武器。支付2把金币，武器获得「灵巧」词条。
- **机械**：仅限射击武器。支付1把金币，武器失去「助进」词条。
- **校准**：仅限射击武器。支付2袋金币，使用该武器对首个射程增量内的角色发动远程攻击时，可以将目标的**被动反射**作为攻击检定的DC。
- **远射**：仅限射击武器。武器的伤害档位+1，使用该武器攻击5格内的角色时攻击检定具有1点妨碍。
- **装填**：武器的伤害档位+1，并获得「弹药，装填」词条。
- **轻型**：武器的伤害档位-1，并获得「轻型」词条。无法同时添加重型、繁琐或双手改装。
- **重型**：武器的伤害档位+1，并获得「重型」词条。无法同时添加轻型改装。
- **繁琐**：武器的伤害档位+1，并获得「繁琐」词条。无法同时添加轻型改装。
- **双手**：武器的伤害档位+1，并获得「双手」词条。无法同时添加轻型或多用改装。
- **可靠**：武器的伤害档位-1，使用该武器的攻击检定+1。
- **强力**：武器的伤害档位+1，使用该武器的攻击检定-1。
- **多用**：支付4把金币，武器获得「多用」词条。无法同时添加双手改装。
- **增距**：支付2把金币，如果武器拥有射程增量，则射程增量+50%。可以重复添加此改装，最多4次。
- **工具**：选择1种工具，支付2把金币，外加所选工具价格的2倍。该武器可以作为所选工具使用。
- **圣化**：支付2袋金币，武器的伤害类型变为纯化，并为该武器添加【sign:圣洁】或【sign:邪秽】标签。

完成改装之后，再为武器添加1种满足条件的精通词条，武器就此设计完成。此时武器的伤害每比模板高1档，你就需要支付2把金币。 \
只有以下改装可以添加在设计完成的武器上：残暴、绞缠、华丽、灵巧、机械、增距、工具、圣化。

#### 武器词条

- **灵巧**：你可以使用敏捷作为灵巧武器的攻击属性。
- **轻型**：轻型武器很适合用于进行双持攻击。
- **重型**：如果你的力量值低于13，无法使用重型武器；如果低于15，使用重型武器发动的攻击检定具有1点妨碍。 \
  被共持的重型武器在判断上述条件时，视你的力量值比实际高2点。
- **繁琐**：如果你的敏捷值低于13，无法使用繁琐武器；如果低于15，使用繁琐武器发动的攻击检定具有1点妨碍。 \
  被共持的繁琐武器在判断上述条件时，视你的敏捷值比实际高2点。
- **触及**：使用触及武器时的触及范围增加1格。这同样会增加你的威胁范围。
- **多用**：共持多用武器时，该武器的伤害档位获得1点状态加值。
- **投掷**：记作「**投掷_N**」，你可以投掷此类武器作为远程攻击，射程增量为N格，并且可以在远程攻击时的伤害检定中加入STR。
- **弹药**：每次使用弹药武器发动攻击都需要消耗1发弹药。若记作「**弹药_N**」，则代表其可以发射弹药进行远程攻击，射程增量为N格。
- **装填**：装填武器每回合最多只能发动1次攻击。
- **装具**：装具武器能够稳定安装在你身上，因此不会占用你的手，也无法被缴械。但想要使用装具武器发动攻击，依然需要你用手持用它。
- **助进**：如果你的STR为正值，那么可以将［STR-2］(最低0) 加入使用助进武器发动的远程攻击的伤害检定 (若原本不行)；否则加入你的完整STR。


#### 精通词条

- **擦掠**：删除该词条。
- **横扫**：每回合1次，使用重型横扫武器发动的攻击命中时，你可以选择源自攻击目标1格光环范围内，除攻击目标外任意个其他生物造成［伤害档位÷2］点横扫伤害，伤害类型与武器相同。 \
  如果本次攻击重击，你可以使攻击目标与所有受到横扫伤害的生物往远离你的方向强制移动1格。
- **迅击**：如果你仅以轻型迅击武器发动双持攻击的副手攻击，则无需为双持攻击消耗附赠动作。
- **推离**：使用推离武器发动的攻击命中时，你可以使用此武器代替体术，以相同的攻击判定值对目标发动1次**推撞**。
- **削弱**：使用削弱武器发动的攻击命中时，目标发动的下次攻击承受1点妨碍，持续1轮。
- **缓速**：使用缓速武器发动的攻击命中时，目标的所有速度受到2点状态减值，并且无法跳跃，持续1轮。如果本次攻击重击，目标还会在此期间陷入【sign:禁足】。
- **失衡**：每回合1次，使用失衡武器发动的攻击命中时，以攻击判定值对抗目标的**被动反射**，成功则其陷入倒地状态。
- **侵扰**：使用侵扰武器发动的攻击命中时，直到你的下个回合结束，你对目标发动的下次攻击获得1点支援。

#### 稳定装置
你可以将稳定装置作为配件安装在重型射击武器上。 \
完成部署的稳定装置能够为你免去重型词条对力量值的需求。

:::{admonition} 便携武器架
便携武器架是一种标准的稳定装置，价值可以忽略不计。 \
部署便携武器架可以作为拔出武器的一部分，收起它则是一个拥有【sign:操作】标签的附赠动作。 \
你必须先收起便携武器架，才能将被安装的武器移动到另一个位置。
:::

#### 武器伤害
若无特别说明，所有武器都造成物理伤害。 \
无论攻击属性，通过武器发动的近战攻击，伤害检定只会加入你的STR。原本改变武器攻击属性的效果，不会改变伤害检定中使用的属性。 \
除非拥有「投掷」或「助进」词条，否则通过武器发动的远程攻击不会加入属性调整值。

#### 射程增量
武器的远程攻击最远能够瞄准6个射程增量内的目标。 \
你与目标的距离每超过1个射程增量，就会在远程攻击检定上承受2点射程减值。


### 护甲
护甲的保护只在你穿戴护甲期间生效。 \
你的（护甲等级:AC）反映了你能防御多强的攻击。以你为目标发动的攻击，通常会将你的AC作为攻击检定的DC。 \
你的基本AC为［闪避值+闪避修正+护甲加值+PB-2］，再加上［⌈人物等级÷2⌉］点RB。
- **闪避值**：你的闪避值初始为10。将闪避值**设置**为特定数值的效果不会叠加，由你择一保留。
- **闪避修正**：你的闪避修正等于DEX。如果你穿戴护甲，闪避修正不会超过护甲的**闪避上限**。 \
  如果你的闪避值包含与闪避修正相同的属性，两者不会叠加。
- **护甲加值**：穿戴受训护甲的期间，如果你的力量值到达护甲列出的力量，AC会获得［基本WPR÷4］点加值。

#### 穿脱护甲
穿脱护甲是很费时的，所以确保你需要它的时候，一定穿着它！ \
穿戴轻甲需要1分钟，中甲和重甲需要5分钟。脱下护甲都需要1分钟。

#### 护甲条目
- **闪避上限**：穿戴护甲的期间，你的AC获得的闪避修正不会超过护甲的闪避上限。
- **防御力与耐久**：你可以执行附赠【cell:能力】，或是成为可见攻击的目标时、在攻击掷骰后使用执行反应【cell:能力】，消耗1点技力，将闪避值设置为［10+防御力］，并且DR获得［防御力］点状态加值，持续至你的下个回合开始。 \
  你可以在此时消耗护甲的1点耐久代替技力。已消耗的耐久会在你完成长休・短休时恢复。耗尽耐久不会对护甲产生任何影响。
- **检定减值**：沉重的护甲会拖累你的行动，DM可以在合适的时机将护甲的检定减值添加在你的行动检定上。如果你的力量值到达护甲列出的力量，该减值减半。
- **速度减值**：你的所有速度都会承受护甲列出的速度减值。如果你的力量值到达护甲列出的力量，该减值减半。

- **嘈杂**：即便力量值到达要求，护甲对隐匿的行动检定造成的检定减值也不会因此减半。

- **柔韧**：护甲对运动的行动检定造成的检定减值减半。若已被减半，改为不会在此时承受护甲的减值。
- **壁垒**：穿戴该护甲的期间，你可以使用STR代替DEX决定闪避修正；如果你的DEX是负值，不会加入反射豁免。

  若你同时陷入基于强度的震慑与缓慢状态，缓慢将被震慑压制。
- **基于时间**：记作「**震慑(持续时间)**」。你会在震慑持续期间陷入失能状态。 \
  基于时间的震慑能够与基于强度的震慑同时存在。
:::

:::{admonition} 疲劳
:class: tip
:name: 疲劳
疲劳期间，你将获得以下效果。
- **强度**：本状态记作「**疲劳[(强度)]**」。重复承受本状态时，将强度叠加来决定效果。
- **HP影响**：你的最大HP减损［PB×强度］点。因此减损的HP无法通过解除疲劳之外的方式恢复。
:::

:::{admonition} 持续伤害
:class: tip
:name: 持续伤害
持续伤害期间，你将获得以下效果。
- **强度**：本状态记作「**持续(伤害类型)伤害(伤害值)**」。 \
  不同伤害类型的本状态视为不同状态；若类型相同，伤害值较低的一方会被压制。
- **伤害**：每当你结束回合时，都会受到列出类型的伤害。
:::

::::{admonition} 屈服
:class: tip
:name: 屈服
屈服状态记作「(轻度|重度)屈服：(种类)」，拥有以下效果。
- 不同种类的屈服视为不同的状态，能够互相叠加。
- 若存在同类的轻度屈服与重度屈服，后者将会压制前者。
- 【次等复原术】以及类似效果可以立即解除角色当前承受的1项轻度屈服。
- 【高等复原术】以及类似效果可以立即解除角色当前承受的1项重度屈服。
- 若屈服的种类与其他状态相同，则会造成相同的效果。在决定其他效果时 (例如免疫)，将该屈服视为同一状态。
- 角色与屈服的具体交互方式由DM决定。
:::{admonition} 驱散屈服
:class: seealso
一名生物每轮最多只会受到1次「驱散屈服」。 \
如果意识到屈服的存在，你或1格内的同伴可以使用【cell:行动】，选择你当前承受的1项屈服作为目标，向DM描述对抗屈服的方式。 \
如果DM认为可行，则你可以重新进行1次对抗屈服的豁免检定。如果该效果无需进行豁免，则改为由采取「驱散屈服」的生物进行1次对抗施加屈服的效果DC的行动检定。
- **成功**：若目标为轻度屈服，则将之解除；若目标为重度屈服，则在累计成功3次时将之解除。
:::

### 标签

:::{admonition} 稀有度
:class: tip
:name: 稀有度
在辨识拥有稀有度的项目信息时，检定DC会根据其稀有度标签获得加值。 \
根据角色的出身与经历，项目的稀有度可能也会发生变化。例如，幽暗地域的怪物对地底居民而言很常见，但对地表居民很罕见。
| 稀有度 | DC调整 |
| :----: | :----: |
|  常见  |   +0   |
|  罕见  |   +2   |
|  稀有  |   +5   |
|  传说  |  +10   |
:::

:::{admonition} 命能
:class: tip
:name: 命能
拥有命能标签的生物会被命能效果治疗、被虚能效果伤害。 \
没有命能标签的生物免疫虚能效果造成的纯化伤害。
:::

:::{admonition} 虚能
:class: tip
:name: 虚能
拥有虚能标签的生物会被命能效果伤害、被虚能效果治疗。 \
没有虚能标签的生物免疫命能效果造成的纯化伤害。
:::

:::{admonition} 圣洁
:class: tip
:name: 圣洁
拥有圣洁标签的生物免疫圣洁效果造成的纯化伤害。 \
没有圣洁标签的生物无法使用圣洁效果。
:::

:::{admonition} 邪秽
:class: tip
:name: 邪秽
拥有邪秽标签的生物免疫邪秽效果造成的纯化伤害。 \
没有邪秽标签的生物无法使用邪秽效果。
:::

:::{admonition} 无魂
:class: tip
:name: 无魂
拥有无魂标签的生物免疫圣洁・邪秽效果造成的纯化伤害。
:::

:::{admonition} 无实体
:class: tip
:name: 无实体
无实体的生物对力场与纯化之外的伤害类型拥有抗性，并免疫非魔法伤害与非自愿且非魔法的物理效果。
:::

:::{admonition} 无心智
:class: tip
:name: 无心智
无心智的生物没有智力属性，并免疫心灵效果，例如拥有心灵标签的伤害、魅惑・恐慌・屈服状态。
:::

:::{admonition} 无感情
:class: tip
:name: 无感情
无感情的生物对抗心灵效果的豁免检定具有优势。
:::

:::{admonition} 无定形
:class: tip
:name: 无定形
无定形的生物对依赖特定解剖结构的效果造成的伤害 (例如武器的重击・偷袭伤害) 拥有抗性，并免疫伤害之外的部分。 \
只要此类生物没有携带或穿着任何物品，就能跻身通过最窄1寸宽的空间。
:::

:::{admonition} 爪牙
:class: tip
:name: 爪牙
爪牙难以对等级相同或更高的PC构成威胁。
- 爪牙无法造成**擦掠伤害**。
- PC对爪牙发动的攻击重击，或是爪牙的典型豁免形成特殊失败时，爪牙将立即死亡。
- 爪牙会在承受任何濒死等级时立即死亡。
:::

:::{admonition} 精英
:class: tip
:name: 精英
精英足以对等级相同或更低的PC构成致命威胁。
- 精英造成的**擦掠伤害**增加2点。
- 当精英受到敌对行为的行动刻时，精英可以使用自由动作发动下列选项之一。如果本场战斗存在多个精英，只有其中1个能够发动选项。
  + **动作**：精英立即执行1个标准动作。
  + **移动**：精英获得［最大速度］点移动力并立即进行移动。
  + **豁免**：精英立即对自身当前承受至少2刻、且允许豁免的所有非自愿效果分别进行1次豁免检定。即使处于无法使用动作的状态，精英依然可以发动本选项。
:::

:::{admonition} 绝技
:class: tip
:name: 绝技
你在每轮通常只能执行1个绝技效果。
:::

:::{admonition} 架势
:class: tip
:name: 架势
执行架势效果时，仍在持续的架势效果将被【cell:解除】。 \
当你陷入【sign:失能】或死亡时，架势效果也会【cell:解除】。
:::

:::{admonition} 符号
:class: tip
:name: 符号
符号标签没有机制上的作用，主要用于决定效果之间的互动。
:::

:::{admonition} 灵能
:class: tip
:name: 灵能
灵能法术可以在无法说话的情况下施展，并且即使有【sign:操作】标签也不会引发借机攻击。 \
灵能标签无法免去【sign:言语】标签对说话的要求。
:::

:::{admonition} 操作
:class: tip
:name: 操作
你需要通过肢体动作来使用操作效果。如果你没有抓握能力，将无法使用操作效果。 \
在生物的威胁范围内使用操作效果将会引发其借机攻击。
:::

:::{admonition} 法器
:class: tip
:name: 法器
你需要用至少1只手持用法器，才能施展【sign:法器】法术。 \
法术所需的法器由给予该法术的特性决定。
:::

:::{admonition} 言语
:class: tip
:name: 言语
影响生物的言语效果，需要该生物听到并理解你的语言，或是你能够与其进行心灵感应才会生效。 \
言语效果中不影响生物的部分，不会在你无法开口说话时生效，为此说话的音量需要能够传递至少10格远。
:::

:::{admonition} 心灵
:class: tip
:name: 心灵
影响心灵的效果拥有心灵标签。【sign:无心智】生物免疫心灵效果。
:::

:::{admonition} 感官
:class: tip
:name: 感官
感官效果基于特定的感官，不会影响未以该感官侦测到效果的生物。
:::

:::{admonition} 刻印
:class: tip
:name: 刻印
如果对受刻印效果影响的目标使用相同类型的刻印效果，会在进入结算阶段时以该效果【word:反制】旧有刻印。
- **反制成功**：【word:解除】目标身上的旧有刻印，使其受到当前使用的刻印效果。
- **反制失败**：该目标免疫当前使用的刻印效果。
:::

:::{admonition} 模式
:class: tip
:name: 模式
当你准备模式法术时，可以根据法术给出的选项客制化法术的效果。 \
你可以重复准备同一道模式法术，重复准备的模式法术视为不同名称的法术。
:::
