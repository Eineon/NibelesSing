# 原念使

## 原念使核心特质
- **主要属性**：感知
- **生命值骰**：D6
- **职业阶位**：中阶WPR、中阶SPR
- **豁免倾向**：反射[弱]、强韧[弱]、意志[强]
- **武器熟练**：简易武器
- **护甲受训**：轻甲
- **职能特性**：【cell:超载】

## 成为原念使

### 作为1级角色
- 获得「原念使核心特质」里的所有能力
- 获得原念使的1级特性

### 作为兼职角色
- 获得「原念使核心特质」里的所有能力
- 获得原念使的1级特性

### 1级：原能念力
原念使能够使用原力——这是一种特殊的法术，它会汲取原念使体内的精神力，可以随意使用。 \
若无特别说明，施展原力均为标准【cell:魔法】。原力无法通过「学习法术」习得。
- **施法属性**：本职业的施法属性为**感知**。
- **施法法器**：本职业使用空着的主手作为施法法器。
- **元素专攻**：从青、赤、黑、金、白中选择1种元素获得专攻。该元素会成为你的**首要元素**。 \
  根据首要元素，原念使的特定豁免倾向会变为强：青 (**强韧**)、赤 (**反射**)、黑 (**强韧**)、金 (**反射**)、白 (**强韧**)。
- **准备原力**：你最高能够准备［⌈本职等级÷2⌉］级原力。「原念使特性」表中的**原力**一列显示了你在每个等级能够准备的辅助原力总数。提升本职等级时，你可以重新准备1项辅助原力。
- **施展原力**：获得首个本职等级时，选择**异能**或**原能**。你施展的原力视为属于所选根源的［⌈本职等级÷2⌉］环罕见法术。

#### 原力注能
你可以对自身施展的念袭原力激活**性质注能**与**塑形注能**。你无法同时激活多个相同类型的注能。若无特别说明，激活注能属于自由动作。 \
如果同时激活多个需要豁免的注能，目标需要先进行塑形注能的豁免，其次进行性质注能的豁免。若目标豁免成功并免受塑形注能的效果，那么它可以免受整个念袭的效果。 \
如果同时激活多个调整伤害的注能，优先应用性质注能的调整。
- **置换注能**：提升本职等级时，你可以放弃任意数量的辅助原力，并准备等量的注能。你也可以在提升本职等级时，将以此准备的注能重新替换回对应的辅助原力。

### 1级：念力凝聚
若你空着主手，则可以在战斗中执行移动【cell:能力】进行念力凝聚。 \
念力凝聚会在以你为中心的4格光环区域创造出异常醒目的感官效果。 \
直到你的下个回合结束为止，你可以标记1点在此期间产生的超载，你需要为此维持专注。 \
你的下个回合结束时，可以消除任意点被标记的超载。 \
你可以重复进行念力凝聚，从而提高标记的超载数量。 \
以此消除超载时，通过承受该超载制造的效果，如果持续时间到达1分钟且不为「永久」，则会变为「谐振」。

### 1级：原力调用
从你的原力根源中，为1~5环的每个环阶各选择2道常见法术，这些法术必须属于你的首要元素对应魔法学派。 \
你将其中不超过［⌈职业等级÷2⌉］环的法术作为辅助原力始终准备。 \
提升本职等级时，你可以重新选择1道法术。
| 元素  | 学派  |
| :---: | :---: |
|  青   | 预言  |
|  赤   | 调灵  |
|  黑   | 嬗变  |
|  金   | 咒法  |
|  白   | 幻术  |

作为辅助原力准备的法术，其原力级别等于法术环阶，施展时无需MP，并具有以下调整。
- 法术获得【sign:灵能】标签。施展时可以将［1~⌈职业等级÷2⌉］作为有效环阶，你需要承受［⌈有效环阶÷2⌉］点超载。
- 若法术的持续时间到达1分钟且不为「永久」，则会在消除因此承受的超载时【word:解除】。
- 重复施展相同法术时，上次施展的该法术将会【word:解除】。

### 2级：超念
你可以通过承受超载，如同塑法专长般调整原力。
- **强效**：你可以承受1点超载，对原力造成1次如同【强效法术】专长**聚能**条目的效果，无需消耗技力。
- **顽强**：7级起，你可以承受2点超载，对原力造成1次如同【顽强法术】专长**聚能**条目的效果，无需消耗技力。
- **瞬发**：12级起，你可以承受3点超载，对原力造成1次如同【瞬发法术】专长**聚能**条目的效果，无需消耗技力。
- **双发**：17级起，你可以在自己的回合施展念袭时承受4点超载，将念袭发动2次。所有调整 (例如注能和其他超念) 都会应用到两发念袭上，你仅需支付单次的超载。

### 2级：适应超载
原念使对自己身体与元素念力进行了长时间的研究，可以在体内存贮额外的能量。 \
你的超载阈值获得［本职等级］点增强加值。

### 3级：灵胜于体
你使用力量・敏捷・体质的行动检定获得等于当前超载值的状态加值，最高［(施法属性值-9)÷4］点。 \
9级起，你的反射・强韧豁免也会获得这项加值。 \
15级起，你的AC与DR也会获得这项加值。

### 3级：元素满溢
无论是否进行超载，你的身体都会充满所选择的能量，这会让你发出盈盈的火光、毛孔渗出水珠或者经受其他与元素相应的效果。 \
你施展原力时的攻击与伤害检定获得等于当前超载值的状态加值，最高［本职等级÷3］点。 \
你可以使用全力动作抑制元素满溢带来的视觉效果与增益。在你下次使用原力时，视觉效果与增益都会立刻恢复。

### 4级：注能熟稔
你每轮为激活注能而承受的超载总值降低［本职等级÷4］点。

### 5级：元素扩展
选择1种元素获得专攻。此后每提升4级，再选择1种元素获得专攻。 \
非首要元素获得的专攻次数不能超过你的首要元素。

### 5级：紧急超载
你可以执行自由【cell:能力】发动<**血术[1]**>，消除1点超载。 \
13级起，改为消除2点超载。

### 6级：咒返念袭
当你成功辨识6格内正在施展、并且属于你的专攻元素对应魔法学派的X环法术时，可以执行反应【cell:魔法】承受［⌈X÷2⌉］点超载，进行1次对抗被辨识法术的【word:反制】。
- **反制成功**：【word:打断】目标施展的法术。你可以立即执行自由【cell:魔法】，使用该元素对施法者发动1次念袭。无法为本次念袭激活注能与**超载增幅**。

### 10级：精通增幅
你为激活念袭原力的<**超载增幅**>而承受的超载可以降低1点。

### 11级：超聚合
你可以使用附赠动作代替移动动作进行念力凝聚。 \
每轮1次，当你使用移动动作行进念力凝聚时，可以额外标记1点超载。

### 14级：元素滋养
进入战斗时，你可以消除最多2点超载。

### 18级：超念大师
选择1种超念选项，将其产生的超载降低1点。

### 19级：传奇恩惠
你获得1项传奇恩惠专长，或其他满足条件的专长。

### 20级：万力全能
你的念袭原力的攻击检定、伤害检定、与豁免DC获得加值，等于主要元素的专攻次数。 \
你可以在施展原力时承受1点超载，以不具备专攻的元素作为主导元素。

### 原力

#### 关键术语
- **元素**：施展原力时，你需要从该原力的「**元素**」条目中选择1种作为主导元素，并获得与该元素对应的魔法学派标签。 \
  你必须对元素拥有专攻，才能选择该元素作为主导元素。 \
  如果条目内的元素后方标有数字，则代表你对该元素的专攻必须到达所标的次数，才能将其作为主导元素。 \
  为念袭原力激活的注法，必须使用与念袭相同的主导元素。
- **超载增幅**：记作「**超载增幅[N]**」。施展原力时，你可以承受N点 (最低1) 超载来激活后方记述的效果。 \
  需要你维持因超载增幅承受的超载的效果，会在你消除这些超载的部分・全部时【word:解除】。

#### 念袭原力
念袭分为2种：能量念袭与物理念袭。你始终准备着所有念袭原力。 \
施展念袭时，指名6格内不具全掩护的一点作为源点，影响源点所在方格内的所有角色。 \
如果源点位于你的触及范围内，将念袭视为近战攻击，反之则视为远程攻击。

【sign:灵能】【sign:法器】\
**元素**：任意 \
发动1次法术攻击，对抗受影响角色的**被动反射**，命中则造成［[环阶]D6+SKM-2］点伤害，类型由主导元素决定。
| 元素  |      伤害类型       |
| :---: | :-----------------: |
|  青   |        虚弱         |
|  赤   |        能量         |
|  黑   |        能量         |
|  金   | 力场 (伤害骰尺寸-2) |
|  白   |        虚弱         |

<**超载增幅[1]**>：伤害提升至［[环阶+2]D6+SKM-2］点。 \
<**超载增幅[2]**>：5级起，伤害提升至［[环阶×2]D6+SKM-2］点。

### 典范专长

#### 元极众妙
*典范* \
**先决**：【原能念力】特性 \
你获得1个众妙注能——一种无须与你首要元素类型相关的性质注能或塑形注能。 \
若该注能原本便能正常应用至你的念袭上，那么你可以如常应用之。但若该注能并非念袭的关连注能，你可以用自由动作承受1点超载，在接下来的［SKM-1］轮内进入**元极众妙**状态中。 \
身处此状态时，即便众妙注能并非该念袭类型关连的注能，你仍可将之应用至念袭上；然而，若某注能只能应用至能量念袭或物理念袭，则你也只能将之应用至该类的念袭上。 \
8级起，以及之后每提升4级，你分别获得1个新的众妙注能。 \
完成长休时，你可以重新选择1个众妙注能，不能超过首次选择时的注能级别。
