# 原念使

## 原念使核心特质
- **主要属性**：感知
- **生命值骰**：D8
- **职业阶位**：中阶WPR、高阶SPR
- **豁免倾向**：反射[强]、强韧[强]、意志[弱]
- **武器熟练**：简易武器
- **护甲受训**：轻甲
- **职能特性**：【cell:超载】

## 成为原念使

### 作为1级角色
- 获得「原念使核心特质」里的所有能力
- 获得原念使的1级特性

### 作为兼职角色
- 获得「原念使核心特质」里的所有能力
- 获得原念使的1级特性

### 1级：原能念力
你获得使用原力的授权，这是一种**聚能法术**。
- **施法属性**：原力的施法属性为**感知**。
- **已知秘源**：能级到达1级的秘源会成为你的**已知秘源**，允许你从中准备原力。 \
  「原念使特性」表中的**能级**一列显示了你每本职等级能够分配的能级总数。
- **准备原力**：你可以从已知秘源中准备［关联秘源能级总和］级以内的原力，它们会成为原念使的本职法术。你始终准备着所有满足条件的念袭原力。 \
  「原念使特性」表中的**超验原力**一列显示了你每本职等级能够准备的超验原力总数。 \
  「原念使特性」表中的**辅助原力**一列显示了你每本职等级能够准备的辅助原力总数。
- **调整能级与原力**：提升本职等级时，你可以调整能级与原力：重新分配1级能级，重新准备1道超验原力，重新准备1道辅助原力。
- **施展原力**：获得首个本职等级时，选择**异能**与**原能**之一，作为你施展的原力所属的根源。施展原力时将本职等级作为SPR，并自动升阶至［⌈本职等级÷2⌉］环。

#### 原力注能
你可以对自身施展的念袭原力激活**性质注能**与**塑形注能**。你无法同时激活多个相同类型的注能。若无特别说明，激活注能属于自由【cell:魔法】。 \
被激活的注能，会将自身的标签与效果加入本次念袭的效果之中。 \
如果同时激活多个需要豁免的注能，目标需要先进行塑形注能的豁免，随后沿用相同的骰值进行性质注能的豁免。若目标豁免成功并免受塑形注能的效果，那么它可以免受整个念袭的效果。 \
如果同时激活多个调整伤害的注能，优先应用性质注能的调整。
- **置换注能**：提升本职等级时，你可以放弃任意数量的辅助原力，并准备等量的注能。你也可以在提升本职等级时，将以此准备的注能重新替换回对应的辅助原力。

### 1级：念力凝聚
若你空着主手，则可以在战斗中执行移动【cell:魔法】进行念力凝聚。 \
念力凝聚会在以你为中心的4格光环区域创造出异常醒目的视觉与听觉效果，并进行专注，持续时间如同「谐振」。 \
维持专注期间仅1次，可以标记1点在此期间承受的超载。若重复进行念力凝聚，能够多次标记超载。 \
被标记的超载不会使你承受疲劳。你可以执行自由【cell:能力】，消除1点持续标记至少1轮的超载。 \
以此消除超载时，通过承受该超载制造的效果，如果持续时间到达10分钟且不为「永久」，则会变为「谐振」。

### 1级：原力调用
从**异能**与**原能**根源中，为0~5环的每个环阶各选择2道常见法术，这些法术必须属于已知秘源对应的魔法学派之一。 \
将其中不超过［⌈职业等级÷2⌉］环的法术作为辅助原力始终准备。 \
提升本职等级时，你可以重新选择1道法术。
| 秘源  | 学派  |
| :---: | :---: |
|  青   | 预言  |
|  赤   | 调灵  |
|  黑   | 嬗变  |
|  金   | 咒法  |
|  白   | 幻术  |

作为辅助原力准备的法术，将会作为原力施展，并具有以下调整。
- 法术获得【sign:灵能】标签，不会自动升阶。施展术法时选择将［1~⌈职业等级÷2⌉］作为有效环阶，你需要承受［⌈有效环阶÷2⌉］点超载。
- 重复施展同名法术时，上次施展的同名法术将会【word:解除】。

### 2级：超念
你可以通过承受超载，如同塑法专长般调整原力。
- **强效**：你可以承受1点超载，对原力造成1次如同【强效法术】专长**聚能**条目的效果，无需消耗技力。
- **顽强**：7级起，你可以承受1点超载，对原力造成1次如同【顽强法术】专长**聚能**条目的效果，无需消耗技力。
- **瞬发**：12级起，你可以承受2点超载，对原力造成1次如同【瞬发法术】专长**聚能**条目的效果，无需消耗技力。
- **双发**：17级起，你可以在自己的回合施展念袭时承受3点超载，将念袭发动2次。所有调整 (例如注能和其他超念) 都会应用到两发念袭上，你仅需支付单次的超载。

### 2级：适应超载
原念使对自己身体与秘源念力进行了长时间的研究，可以在体内存贮额外的能量。 \
你的超载阈值获得［本职等级］点增强加值。

### 3级：灵胜于体
你使用力量・敏捷・体质的行动检定获得等于当前超载值的状态加值，最高［(施法属性值-9)÷4］点。 \
6级起，你的反射・强韧豁免也会获得这项状态加值。 \
10级起，你的AC与DR也会获得这项状态加值。

### 3级：秘源满溢
无论是否进行超载，你的身体都会充满秘源能量，这会让你发出盈盈的火光、毛孔渗出水珠或者经受其他与秘源相应的效果。 \
你使用原力的攻击与伤害检定获得等于当前超载值的状态加值，最高［本职等级÷3］点。 \
你可以使用全力动作抑制秘源满溢带来的视觉效果与增益。在你下次使用原力时，视觉效果与增益都会立刻恢复。

### 3级：秘源境界
你可以执行全力【cell:魔法】，展开体内原始的秘源能量，形成以你为中心4格光环区域的秘源境界，持续时间如同「谐振」。
- 你可以执行自由【cell:能力】主动【word:解除】境界。
- 当你昏迷・死亡时，境界将会【word:解除】。
- 境界无法覆盖受【反魔法力场】法术及类似效果影响的空间。
- 境界的空间会对你的敌人形成阻碍区域。
- 展开境界时，你获得［⌈本职等级÷4⌉+SKM-2］点技力，持续至境界结束。这些技力只能用于发动境界技艺。
- 展开境界后，直到完成一次长休・短休，你无法再次展开境界。你可以执行自由【cell:能力】承受2点超载，立即恢复境界的使用权。

你习得以下境界技艺之一。5级起，以及之后每提升4级，分别习得1项新的境界技艺。 \
若境界技艺的效果要求豁免，则使用你的法术豁免DC。

#### 境界技艺：梦想显形
你可以执行附赠【cell:魔法】，或是作为展开境界的一部分，指名境界内你可见的1点。 \
作为【sign:学派:幻术】效果，在目标方格创造一个幻象。从以下效果中选择一项，作为幻象的效果。离开境界的幻象将会消失。
- 选择1种感官，侦测幻象所在空间的所选感官将受到重度遮蔽，持续1轮。你可以消耗1点技力，额外选择1种感官。
- 如同【无声幻影】法术，但体积不超过1格，持续1轮。你可以消耗1点技力，将持续时间延长至［SKM-1］轮。

#### 境界技艺：精神协作
你可以执行附赠【cell:魔法】，或是作为展开境界的一部分，消耗1点技力，指名境界内的1个可见同伴，使目标在境界内进行的下次D20检定获得［你的SKM］点加值，或是下次伤害检定获得［你的SKM×2］点加值，持续1轮。

#### 境界技艺：回响庇护
你可以执行附赠【cell:魔法】，或是作为展开境界的一部分，消耗最多［⌈本职等级÷4⌉］点技力，使你或境界内的1个同伴，AC与DR获得［技力消耗］点内在加值，持续至你再次使用本技艺、境界结束、或是离开境界。

#### 境界技艺：疆界转移
你可以在自己的回合执行附赠【cell:魔法】，或是作为展开境界的一部分，消耗1点技力，从以下效果中选择1项。
1. 你传送至境界内一处你可见且未被占据的空间。 \
  境界的效果区域会暂时留在原地，持续1轮。在此期间，你对任何侦测你的感官具有轻度遮蔽。
2. 你将境界的起点传送至境界区域内你可见的一点，持续至境界结束。你可以执行附赠【cell:能力】将起点传送回自己身上。

#### 境界技艺：延迟念袭
施展念袭时，你可以从1轮到5轮之间指定一个轮数。当你指定的轮数经过后，这道念袭会在你的回合开始时发射。
- 你需要为念袭维持专注。若专注被打断，每道念袭都会爆炸，对你以及周围2格光环区域内所有生物造成［[念袭环阶]D4］点力场伤害，此伤害不会获得任何加值。
- 念袭会漂浮在你占据的空间中，可以被【解除魔法】法术所解除。
- 你可以执行移动【cell:魔法】，提前发射1道念袭。
- 你需要在施展念袭时激活注能，在发射时指名目标。
- 每成功延迟1轮，念袭的攻击・伤害检定与DC便会获得1点内在加值。

#### 境界技艺：咒返念袭
境界内的可见生物施展属于你的已知秘源对应的魔法学派之一的X环法术时，你可以执行反应【cell:魔法】消耗［⌈X÷2⌉］点技力，进行1次对抗该法术的【word:反制】。
- **反制成功**：【word:打断】目标施展的法术。你可以立即执行自由【cell:魔法】，使用相同秘源对施法者施展1次念袭。无法为本次念袭激活注能与**超载增幅**。

维持专注的生物进入境界，或是在境界内开始回合时，你可以执行反应【cell:魔法】消耗1点技力，迫使目标使用进行1次专注检定，对抗你的法术DC，失败则打断专注。

#### 境界技艺：促进注能
当你激活注能时，可以执行自由【cell:魔法】消耗1点技力，将该注法产生的超载降低1点。 \
相同注能每轮最多只会被本技艺影响1次。

#### 境界技艺：原力牢笼
生物进入境界，或是在境界内开始回合时，你可以执行自由【cell:魔法】消耗1点技力，迫使目标进行1次反射豁免，失败则陷入【sign:禁足】，持续至境界结束。 \
因此禁足的期间，目标无法进行传送。目标可以执行移动【cell:能力】重新进行豁免，成功则解除禁足。 \
一个生物每轮最多只会被本技艺影响1次。

#### 境界技艺：伏魔领域
你可以在展开境界时承受2点超载，并选择1个已知秘源。 \
生物进入境界，或是在境界内开始回合时，你可以执行自由【cell:魔法】，对其造成［⌈1+本职等级÷4⌉D8］点伤害。你可以消耗1点技力，增加2枚伤害骰。 \
该生物可以进行1次典型豁免检定。伤害类型与豁免类型由所选秘源决定。 \
一个生物每轮最多只会被本技艺影响1次。
| 秘源  |         伤害类型          |  豁免类型  |
| :---: | :-----------------------: | :--------: |
|  青   |        灼烧・虚弱         | 强韧・意志 |
|  赤   |   纯化 (选择命能或虚能)   | 强韧・意志 |
|  黑   |  物理・腐蚀・灼烧・冷冻   | 反射・强韧 |
|  金   | 腐蚀・力场 (伤害骰尺寸-2) | 反射・强韧 |
|  白   |        冷冻・虚弱         | 强韧・意志 |

#### 境界技艺：无界领域
你可以在展开境界时承受［1~⌈本职等级÷4⌉］点超载，为境界添加以下效果。
- 境界区域的规模增加［因此承受的超载×2］格。
- 境界可以绕过拐角扩散。
- 你可以将触觉作为**精确感官**，侦测境界内的事物。
- 施展念袭时，你可以将境界内可见的任意一点作为效果的起点。

#### 境界技艺：共鸣连觉
你可以在展开境界时承受［1~⌈本职等级÷4⌉］点超载，为境界添加以下效果。
- 展开境界、以及展开境界后每轮开始时，作为【sign:心灵】效果，你可以执行自由【cell:魔法】，指名境界内的1个生物作为连觉对象，持续至境界结束。
- 非自愿生物可以在被指名、以及连觉后每个自身的回合结束时进行1次意志豁免，成功则免受连觉。
- 你最多可以同时维持［SKM］个连觉对象。你需要为此维持专注，所有连觉对象仅视为一次专注。
- 连觉对象的回合开始时，你可以对其造成以下效果之一。
  1. 连觉对象获得［因此承受的超载×5］点内在韧性，持续1轮。
  2. 连觉对象的专注检定，以及对抗【sign:心灵】效果的豁免检定获得［因此承受的超载］点状态加值，持续1轮。
  3. 每刻1次，连觉对象对你，或是你的连觉对象造成伤害时，将受到［因此承受的超载×5］点虚弱[精神]伤害，持续1轮。
  4. 连觉对象陷入对你的魅惑・恐慌状态，持续1轮。

### 4级：注能熟稔
你每轮为激活注能而承受的超载总值降低［本职等级÷4］点。

### 6级：紧急超载
你可以执行自由【cell:魔法】发动<**血术[1]**>，消除1点超载。 \
15级起，改为消除最多2点超载。

### 7级：次级秘源
选择1个秘源作为你的次级秘源，将其能级提升至1级 (若为0级)。 \
在决定任何「关联秘源能级总和」时，有效能级不会超过［⌈本职等级÷4⌉］级。 \
15级起，再获得1个新的次级秘源，或将已有的次级秘源能级提升至2级 (若拥有能级3+的秘源)。

### 10级：精通增幅
你为激活念袭原力的<**超载增幅**>而承受的超载可以降低1点。

### 11级：超聚合
你可以使用附赠动作代替移动动作进行念力凝聚。 \
每轮1次，当你使用移动动作行进念力凝聚时，可以额外标记1点超载。

### 12级：秘源滋养
原念使HD尺寸提升至10点，意志豁免的倾向变为强。

### 14级：重塑现实
展开【秘源境界】的期间，你可以执行标准【cell:魔法】，选择1个已知秘源，以自由【cell:魔法】施展1道常见法术的［1~所选秘源能级×2］环版本。
- 该法术必须属于所选秘源对应魔法学派。
- 该法术可以来自任意魔法根源，不能是聚能法术。你不需要准备该法术。
- 该法术获得【sign:灵能】标签，并且无需MP。

以此施展法术后，你无法再使用本特性，直到你完成一次长休。

### 18级：超念大师
选择1种超念选项，将其产生的超载降低1点。

### 19级：传奇恩惠
你获得1项传奇恩惠专长，或其他满足条件的专长。

### 20级：万力全能
你使用念袭原力的攻击检定、伤害检定、与豁免DC获得加值，等于主导秘源的能级。 \
你可以在施展原力时承受1点超载，以非已知的秘源作为主导秘源。

### 原力

#### 原力条目
- **级别**：你可以从已知秘源中准备［关联秘源能级总和］级以内的原力。
- **秘源**：此处列出了原力的关联秘源。施展原力时，你需要从中选择1个已知秘源作为主导秘源，并获得与该秘源对应的魔法学派标签。 \
  为念袭原力激活的注法，必须使用与念袭相同的主导秘源。
- **先决**：你只能准备满足先决条件的原力。若条件失效，你将暂时失去该原力，直到条件被重新满足。
- **需求**：你只能发动满足需求条件的原力。如果你不再满足正在持续的原力的需求条件，效果将被【word:解除】。
- **施法时间**：所有原力都需要执行【cell:魔法】施展。此处列出了施展原力所消耗的行动权。消耗标准动作的原力不会显示本条目。
- **施法频率**：此处列出了原力在特定时间内能够施展的次数上限。没有次数限制的原力不会显示本条目。
- **超载增幅**：记作「**超载增幅[N]**」。施展原力时，你可以承受N点 (最低1) 超载来激活后方记述的效果。
- **能级**：记作「**能级[N]**」。若你对原力关联秘源能级总和到达N级，则会获得此处记述的效果。
