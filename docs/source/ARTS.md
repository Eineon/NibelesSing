# 武术

## 发动武术
武术可以被归类为两大类别：**招式**与**功法**。发动招式需要消耗**机略**，功法则是持续生效的被动增益。
- **机略**：每轮开始时，你获得［⌈武艺等级÷4⌉］点机略。未消耗的机略会在下一轮开始时消失。 \
  若遭到【word:突袭】，获得机略的时机将延后至突袭轮第一个你的回合开始时。
- **功法**：你同时只能维持1项功法。功法的效果会永久持续。你可以执行附赠【cell:能力】主动解除功法。
- **武术攻击调整值**：如果发动要求你进行武术攻击检定的武术，其攻击检定调整值为［PB+MKM］，并获得［武艺等级÷2］点RB。
- **武术DC**：如果发动要求豁免的武术，其豁免DC为［10+PB+MKM］，并获得［武艺等级÷2］点RB。若该武术需要使用武器，你可以用攻击DC作为武术DC。
- **武术与魔法**：不具【sign:符号:魔法】或【sign:根源】标签的武术属于非魔法效果，反之则为魔法效果。

### 武术条目
- **强度**：武术拥有［⌈武艺等级÷2⌉］级强度。
- **级别**：你无法准备超过［流派造诣］级的武术。发动招式时，你需要消耗等于武术级别的机略。
- **先决**：你只能准备满足先决条件的武术。若条件失效，你将暂时失去该武术，直到条件被重新满足。
- **需求**：你只能激活满足需求条件的武术。如果你不再满足正在持续的武术的需求条件，效果将被【word:解除】。
- **激活**：所有武术都需要执行【cell:战技】激活。此处列出了激活武术所消耗的行动权。
  + **迸放**：你需要执行标准【cell:战技】激活条目中包含「迸放」的武术。可以一次性激活多个迸放武术，还可以重复激活相同武术。 \
    你也可以在执行【cell:打击】时激活迸放武术，每次激活都需要消耗1次主手攻击。 \
    所消耗的攻击因全力攻击承受的减值，也会作用在武术的攻击检定与豁免DC上。
- **频率**：此处列出了武术在特定时间内能够激活的次数上限。没有次数限制的武术不会显示本条目。

### 武术流派
获得首个武艺等级时，你拥有1点**造诣**。武艺之后每提升4级，再获得1点造诣。 \
你可以将造诣分配在流派上，拥有至少1点造诣的流派会成为**已知流派**，允许你从中准备武术。 \
提升武艺等级时，你可以重新分配1点造诣。

#### 流派武器
每种流派都拥有独特的武器偏好。你对所有已知流派的流派武器拥有熟练。 \
除非特别说明，否则你可以使用不属于流派武器的武器发动该流派的武术，此时该武术的武术攻击检定与武术DC-2。

##### 控字诀｜0级
【sign:架势】 \
**类别**：功法 \
**激活**：附赠动作 \
当处于【sign:禁足】的生物对除你之外的生物发动攻击时，进行的攻击检定受到［⌈武艺等级÷5⌉］点妨碍。 \
