# 武术

## 发动武术
武术可以被归类为三大类别：**招式**、**技法**与**功法**。
- **机略**：每轮开始时，你获得［⌈武艺等级÷4⌉］点机略。未消耗的机略会在下一轮开始时消失。 \
  若遭到【word:突袭】，获得机略的时机将延后至突袭轮第一个你的回合开始时。 \
  发动招式时，你需要消耗等于武术级别的机略。
- **功法**：所有功法都属于【sign:架势】效果。功法的效果会永久持续。你可以执行附赠【cell:能力】主动解除功法。
- **武术攻击调整值**：如果发动要求你进行武术攻击检定的武术，其攻击检定调整值为［PB+MKM］，并获得［武艺等级÷2］点RB。
- **武术DC**：如果发动要求豁免的武术，其豁免DC为［10+PB+MKM］，并获得［武艺等级÷2］点RB。若该武术需要使用武器，你可以用攻击DC作为武术DC。
- **武术与魔法**：不具【sign:符号:魔法】或【sign:根源】标签的武术属于非魔法效果，反之则为魔法效果。

### 武术条目
- **强度**：武术拥有［⌈武艺等级÷2⌉］级强度。
- **级别**：你可以从已知流派中准备［流派造诣］级以内的武术。
- **先决**：你只能准备满足先决条件的武术。若条件失效，你将暂时失去该武术，直到条件被重新满足。
- **需求**：你只能发动满足需求条件的武术。如果你不再满足正在持续的武术的需求条件，效果将被【word:解除】。
- **发动**：所有武术都需要执行【cell:战技】发动。此处列出了发动武术所消耗的行动权。
  + **迸放**：你需要执行标准【cell:战技】发动条目中包含「迸放」的武术。可以一次性发动多个迸放武术，还可以重复发动相同武术。 \
    你也可以在执行【cell:打击】时发动迸放武术，每次发动都需要消耗1次主手攻击。 \
    所消耗的攻击因全力攻击承受的减值，也会作用在武术的攻击检定与豁免DC上。
- **频率**：此处列出了武术在特定时间内能够发动的次数上限。没有次数限制的武术不会显示本条目。
- **造诣**：记作「**造诣[N]**」。若你对武术所属流派的造诣到达N点，则会获得此处记述的效果。

#### 流派武器
每种流派都拥有独特的武器偏好。你对所有已知流派的流派武器拥有熟练。 \
除非特别说明，否则你可以使用不属于流派武器的武器发动该流派的武术，此时通过该武术进行的攻击检定与豁免DC将受到2点减值。


## 流派列表

### 愚行
**流派武器**：肉体武器，临时武器，轻型武器

#### 一级

##### 禁足击｜1级
**类别**：招式 \
**发动**：迸放 \
指名触及范围内的1个角色，对目标发动1次近战武器攻击。 \
<**聚能[1]**>：发动本武术时作为自由【cell:战技】。迫使攻击目标进行1次反射・意志豁免 (准备时选择)，失败则陷入【sign:禁足】，持续时间如同「谐振」。 \
因此禁足的期间，目标可以执行移动【cell:能力】重新进行豁免，成功则解除禁足。 \
<**造诣[2]**>：若目标对抗本武术聚能效果的豁免检定成功，其所有速度受到2点状态减值，并且无法跳跃，持续1轮。

##### 旋身击｜1级
**类别**：招式 \
**发动**：迸放 \
指名触及范围内的1个角色，对目标发动1次近战武器攻击。 \
<**聚能[1]**>：发动本武术时作为自由【cell:战技】。迫使攻击目标进行1次反射豁免，失败则将目标强制移动最多2格。

##### 粉碎击｜1级
【sign:绝技】 \
**类别**：招式 \
**发动**：迸放 \
消耗1点技力，指名触及范围内的1个角色，对目标发动2次流派武器攻击。 \
以此发动的攻击检定受到2点减值，两次伤害仅计算1次DR与硬度。

##### 飞身踢｜1级
**类别**：招式 \
**发动**：迸放 \
**频率**：每轮1次 \
指名触及范围内的1个角色，对目标发动1次近战武器攻击。 \
<**聚能[1]**>：发动本武术时作为自由【cell:战技】。你可以在攻击之前或之后立即进行1次跳跃，无需附赠动作与移动力，并且跳跃长度提升至［最大速度］格。

##### 锁步｜1级
**类别**：技法 \
**发动**：反应动作，你的触及范围内处于【sign:禁足】的可见生物发动攻击时 \
消耗1点技力，尝试【word:反制】对方攻击，使用运动进行行动检定作为反制检定，将目标的攻击判定值作为DC。
- **反制成功**：【word:打断】对方攻击。

##### 牵引步伐｜1级
**类别**：技法 \
**发动**：反应动作，你的武器攻击命中时 \
消耗1点技力，迫使目标进行1次反射・意志豁免 (准备时选择)，失败则陷入【sign:禁足】，持续时间如同「谐振」。 \
因此禁足的期间，目标可以执行移动【cell:能力】重新进行豁免，成功则解除禁足。

##### 连环拳｜1级
【sign:绝技】 \
**类别**：技法 \
**发动**：附赠动作，你执行【cell:打击】时 \
本次【cell:打击】能够以流派武器额外发动1次攻击。 \
对全力攻击发动本武术无需消耗附赠动作。

##### 无二打｜1级
**类别**：技法 \
**发动**：自由动作，你执行【cell:打击】时 \
消耗本回合X次流派武器的攻击次数，令本次【cell:打击】的其中1次使用流派武器的攻击检定+X，命中时额外造成［[X]WD］点相同类型的伤害。

##### 闪身切入｜1级
**类别**：技法 \
**发动**：附赠动作 \
消耗1点技力，指名1个与你相邻的生物。 \
即时移动最多［最大速度］格，至与目标相邻且未被占据的空间中。 \
1轮内，目标对你对其发动的下次武器攻击具有【sign:破绽】。

##### 十步一杀｜1级
**类别**：技法 \
**发动**：附赠动作 \
**持续时间**：1轮 \
消耗1点技力，你发动的下次武器攻击，触及距离延长至6格。

##### 控字诀｜1级
【sign:架势】 \
**类别**：功法 \
**发动**：附赠动作 \
当处于【sign:禁足】的生物对除你之外的生物发动攻击时，进行的攻击检定受到1点妨碍。 \
武术持续期间每轮1次，你发动的肉体武器攻击命中时作为自由【cell:战技】，你可以迫使目标进行1次反射・意志豁免 (准备时选择)，失败则陷入【sign:禁足】，持续时间如同「谐振」。 \
因此禁足的期间，目标可以执行移动【cell:能力】重新进行豁免，成功则解除禁足。

##### 衡字诀｜1级
【sign:架势】 \
**类别**：功法 \
**发动**：附赠动作 \
武术持续期间，你获得以下增益。
- 你可以将闪避值设置为［10+MKM］。
- 若未穿戴护甲，你的AC与DR获得［愚行造诣］点状态加值。
- 你可以使用武艺档位作为流派武器的伤害档位。
- 你能够以附赠动作执行【cell:起身】，并且不会引发借机攻击。
- 你使用运动的行动检定获得专精。

<**造诣[2]**>：武术持续期间，你获得等于步行速度的攀爬速度。

#### 二级

##### 龙卷摔｜2级
**先决**：旋身击 \
**类别**：招式 \
**发动**：迸放 \
指名触及范围内的1个角色，对目标发动1次近战武器攻击。 \
<**聚能[1]**>：发动本武术时作为自由【cell:战技】。迫使攻击目标进行1次反射豁免，失败则将目标强制移动最多6格，并且目标会在移动结束后陷入倒地。 \
强制移动结束后，你可以即时移动至任意与目标相邻且未被占据的空间，随后使其陷入【sign:禁足】，持续时间如同「谐振」。 \
因此禁足的期间，目标可以执行移动【cell:能力】进行反射・意志豁免 (准备时选择)，成功则解除禁足。

##### 风车旋舞｜2级
【sign:绝技】 \
**类别**：招式 \
**发动**：迸放 \
消耗1点技力，发动2次流派武器攻击。 \
以此发动的攻击检定受到2点减值。每次攻击之前或之后，你可以进行1格即时移动。 \
此外，发动本武术之前或之后，你可以进行最多［最大速度］格即时移动。

##### 夜深人静｜2级
**类别**：招式 \
**发动**：迸放 \
指名触及范围内的1个角色，对目标发动1次近战武器攻击。 \
<**聚能[1]**>：对禁足生物发动本武术时作为自由【cell:战技】。目标会在禁足期间陷入【sign:破绽】与【sign:失声】。

##### 卸武夺刀｜2级
**类别**：技法 \
**发动**：反应动作，你成为可见的武器攻击的目标时 \
消耗1点技力，尝试【word:反制】对方攻击，使用运动进行行动检定作为反制检定，将目标的攻击判定值作为DC。
- **反制成功**：【word:打断】对方攻击。若对方使用白刃武器，且身处你的触及范围内，则可以使目标陷入【cell:缴械】，持续1刻。 \
  你可以用空手接住对方因被缴械而脱手的武器。

##### 以力缚人｜2级
**类别**：技法 \
**发动**：反应动作，你给予的【sign:禁足】即将因非自愿效果而【word:解除】时 \
消耗1点技力，尝试【word:反制】触发源，使用运动进行行动检定作为反制检定。
- **反制成功**：【word:打断】或【word:解除】触发源。

##### 描头画角｜2级
**类别**：技法 \
**发动**：反应动作，你辨识出6格内的可见生物发动级别不超过［愚行造诣］级的招式或技法时 \
消耗1点技力，你临时准备作为触发源的武术，并无视准备该武术所需的流派造诣。你依然需要满足该武术的先决与需求条件。 \
一旦发动该临时武术，它便会从你的武术准备列表中消失。你的准备列表同时只能存在1个临时武术。

##### 迫字诀｜2级
【sign:架势】 \
**类别**：功法 \
**先决**：控字诀 \
**发动**：附赠动作 \
你获得【控字诀】的所有效果，并且武术持续期间每轮1次，对处于禁足的目标发动武器攻击时，你可以执行自由【cell:战技】，使目标对本次攻击具有【sign:破绽】。
